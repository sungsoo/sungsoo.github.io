# HAI 연구 제안 보완 — 2026-11-10

모두 미검증 제안. 초기5개 제안은 보존하며 관련되는 부분만 확장.

## R1-G 승인된 목표와 추정 목표의 경계

- 문헌 관계: P30;초기 R1·R5 확장
- 가설: 수정 가능 목표는 정적 프로필보다 목표 변경 후 오적용을 줄인다는 가설
- 비교군: 정적 프로필 / 출처·승인 상태가 있는 목표표 / 목표 변경시 재확인;동일 모델·정보·확인 예산
- 대상·과제·데이터: 성인 연구자·지식근로자의 공개 문헌 기획;합성 목표 변경;실제 외부 게시 없음
- 지표: 일차:오래된 목표 오적용률;보조:최종 품질·검토시간·설정 이해
- 분석: 참가자·과업 혼합모형;최소 의미 효과와 시간 비열등 한계 사전등록
- 반증 조건: 오적용 차이 구간이 최소 효과 미달 또는 시간 손실 한계 초과이면 미지지
- 부담: 중간;로컬 상태기계·버전 저장으로 시작

## R2-A 주장–근거 계보의 수정 효과

- 문헌 관계: P31;초기 R2 구체화
- 가설: 같은 정보량에서 편집 그래프는 평면 근거표보다 새 반례에 대한 올바른 결론 수정을 높인다는 가설
- 비교군: 대화 / 평면 근거표 / 편집 가능한 논증;동일 출처·정보량·시간 예산
- 대상·과제·데이터: 공개 논문 자료와 합성 정정;저장소·문서군 분할;미래 정정 라벨 차단
- 지표: 일차:블라인드 결론 수정 정확도;보조:가정 오류 탐지·시간·지연 무보조 이해
- 분석: 교차 무작위 효과;독립 평가자;구성요소 제거;다중비교 계획
- 반증 조건: 정보량 일치 후 이득 소멸 또는 무보조 이해 저하이면 구조 우위 미지지
- 부담: 낮음~중간;SQLite·그래프 질의·편집 UI

## R4-S 검사 가능한 적응 입력

- 문헌 관계: P32;초기 R4의 선택권 연구를 입력 측면으로 확장
- 가설: 입력 상태와 차단 결과의 표시가 고지만 제공한 조건보다 실제 사용 상태 이해를 높인다는 가설
- 비교군: 고지문 / 고지+설정 / 고지+검증 가능한 차단;고지 시점 별도 무작위화
- 대상·과제·데이터: 비민감 업무 안내;우선 합성 센서 스트림;몰래 실제 생체 측정하지 않음
- 지표: 일차:입력 사용 상태 예측 정확도;보조:철회 후전송0건·정답률·부담
- 분석: 설정·고지의 독립 요인;참가자·과업 반복측정;신호와 언어 내용 통제
- 반증 조건: 고지 시점·순서 통제 후 이해 차이 소멸 또는 차단후전송 발생이면 실패
- 부담: 중간;모의 데이터 경로 감사 우선

## R5-C 지원과 대행의 무보조 전이

- 문헌 관계: P33;초기 R3·R5 연결
- 가설: 연습 지원은 직접 대행보다 지연 무보조 수행을 높이며 즉시 품질은 허용범위 내 유지한다는 가설
- 비교군: 직접 작성 / 질문·연습 / 비사용;시간 예산과 정보량 일치
- 대상·과제·데이터: 성인 연구자의 비민감 검토·협업 대화;정서적 의존 유도 제외
- 지표: 일차:지연 무보조 수행의 블라인드 평가;보조:즉시 품질·부담·사용 맥락
- 분석: 기저 기술·여력·정보는 탐색적 조절변수;탈락·결측 민감도;척도 검증 선행
- 반증 조건: 자가보고 도움만 증가하거나 지연 수행에서 이득이 없으면 역량 유지 주장 보류
- 부담: 높음;반복 방문·평가자·측정 도구 필요

우선 R2-A의 오프라인 정정 추적과 정보량 통제를 검증하고, 다음 R1-G의 목표 변경 실험을 권한다. R4-S는 합성 센서 감사부터, R5-C는 반복 참여와 측정 부담 때문에 후속 단계로 둔다. 표본 수는 임의로 정하지 않고 파일럿 분산·참가자 내 상관·최소 의미 효과·탈락을 반영한 검정력 시뮬레이션으로 정한다. 참가자 동의·보상·중단권·개인정보 최소화·필요한 기관 심의를 거친 뒤 사람 대상 연구를 수행한다. 분석 전 주 지표·핵심 대비·허용 손실·제외·결측·중단·다중비교 규칙을 고정한다. 초기 R3·R4와 전체 원 제안은 원문 링크로 함께 제공한다.
