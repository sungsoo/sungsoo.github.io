# HAI 연구 제안 보완 — 2026-11-09

모두 미검증 제안. 초기R3·R4는 유지.

## R1+ 확인 위치와 실제 복구

- 선행근거와 관계: P27·P28; 초기R1 확장
- 비교군: 단순 확인 / 고정 주기 / 영향 기반 확인;확인 수·정보량 일치
- 과제·데이터: 모의 문헌검토→편집→공개;실제 외부 전송 없음
- 지표: 일차:권한 위반 방지율;보조:복구 성공·완료시간·부담
- 분석: 참가자·과업 혼합모형;최소 의미 효과 사전 고정
- 반증 조건: 방지율 구간이 최소 효과 미달 또는 시간 한계 초과 시 미지지

## R2+ 계보와 실행 가능한 설명

- 선행근거와 관계: P27·P28; 초기R2 확장
- 비교군: 대화 / 평면 이벤트 / 계보 그래프;저장량·노출정보 통제
- 과제·데이터: 공개·합성 추적;과제·저장소 단위 분할;미래 라벨 차단
- 지표: 일차:블라인드 원인 복원 정확도;보조:검토시간·오탐·질의p95
- 분석: paired bootstrap;필드 제거;독립 평가자;라이선스 선확인
- 반증 조건: 최종 라벨 제거 또는 정보량 일치 후 이득 소멸이면 구조 기여 미지지

## R5+ 기억과 반응 양식 분리

- 선행근거와 관계: P29; 초기R5 보완
- 비교군: 기억 유무×중립/근거 있는 반례;내용·어조 통제
- 과제·데이터: 비민감 업무 반복 사용;정서적 의존 유도 제외
- 지표: 일차:목표 변경 후 잘못된 선호 적용;보조:효용·자가보고
- 분석: 혼합모형;탈락 민감도;후속 무보조 과제
- 반증 조건: 효과가 순간 선호에만 있거나 지연 행동에 없으면 지속 개선 주장 보류

우선순위는 R2+의 오프라인 스키마 검증, 다음 R1+의 사용자 실험이다. R5+는 반복 참여와 개인정보 관리 부담 때문에 후속으로 둔다. 대상은 AI 경험이 다른 성인 연구자·지식근로자로 제안한다. 표본은 임의 고정하지 않고 파일럿 분산·최소 의미 효과·과업 내 상관·탈락을 반영한 검정력 분석으로 정한다. 실제 모집 전 동의·보상·중단권·필요한 기관 심의를 갖추고 민감 원문 대신 최소 이벤트를 수집한다. 이번에 사람 모집·구현·실험은 수행하지 않았다.

## 가설과 공통 사전 고정

R2+의 계보는 같은 정보량의 평면 기록보다 원인 복원을 높이고, R1+는 같은 확인 예산에서 경계 위반을 줄인다는 가설이다. R5+의 목표는 기억의 유용성을 유지하면서 오래된 선호의 오적용을 줄이는 것이다. 결과를 보기 전에 허용 시간·최소 효과·제외·결측·다중비교 규칙을 고정한다. 초기 R3·R4는 원 제안 문서의 내용을 유지한다.
