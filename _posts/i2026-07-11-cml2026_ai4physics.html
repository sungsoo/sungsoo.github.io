00
Scope & Reliability

분석 범위와 자료 신뢰도

ICML 2026 AI4Physics 워크숍의 초청 강연, 구두 발표, 포스터 목록을 하나의 연구 코퍼스로 보고 공통 개념과 연구질문을 재구성한다.

워크숍은 비아카이벌 정책을 채택한다. 일부 논문은 arXiv 또는 OpenReview 원문이 공개되어 있지만, 일부 항목은 제목·초록·카메라레디 정보만 확인된다. 따라서 공개 원문이 확인되는 연구는 직접 근거로 사용하고, 나머지는 공식 프로그램과 제목에서 식별되는 연구축을 중심으로 통합한다.

전체 연구 지형을 구성하는 여섯 축

AXIS 01
과학 에이전트

문헌·코드·시뮬레이터를 사용해 가설 설정, 계산, 비평, 검증을 반복한다.

AXIS 02
학습형 시뮬레이터

PDE와 동역학의 고비용 수치해석을 빠른 대리모델로 근사한다.

AXIS 03
물리 제약

보존법칙, 대칭성, 안정성, 허용영역을 모델 구조와 최적화에 내장한다.

AXIS 04
역문제·불확실성

잡음이 있는 부분 관측으로부터 숨겨진 상태와 파라미터의 사후분포를 추론한다.

AXIS 05
물리 기초모델

서로 다른 방정식, 레짐, geometry를 하나의 문맥 조건 모델로 통합한다.

AXIS 06
검증 벤치마크

최종 답뿐 아니라 연구 절차, 도구 사용, 오류 복구, 형식화를 평가한다.

01
Definition

AI for Physics의 정의

AI for Physics는 물리 데이터를 단순 회귀하거나 분류하는 머신러닝이 아니다. 표현·시뮬레이션·추론·행동·검증을 하나의 계산 체계로 결합하는 연구 영역이다.

AI for Physics = Representation + Simulation + Inference + Action + Verification
Representation

물리 상태 표현

입자, 장, 분자, 그래프, 격자, 시계열을 학습 가능한 구조로 변환한다.

Simulation

미래 상태 예측

초기·경계조건과 물성으로부터 시간에 따른 상태 변화를 근사한다.

Inference

숨은 원인 복원

관측으로부터 파라미터, 초기조건, 잠재상태와 사후분포를 추론한다.

Action

설계·제어 결정

실험 조건, 제어 입력, 구조 설계 변수를 선택해 목적함수를 최적화한다.

Verification

과학적 타당성 검사

물리법칙, 수학적 제약, 단위, 인과성, 불확실성을 독립적으로 확인한다.

Scientific System

폐루프 연구 수행

문헌 검색에서 실험 설계와 반증까지 연속된 연구 워크플로를 구성한다.

학습형 물리 시스템

F(u, ∂u/∂t, ∇u, ∇²u ; λ, b) = 0

물리 상태 u, 시스템 파라미터 λ, 초기·경계조건 b가 주어진다. 학습 모델은 고비용 수치해석기를 반복 실행하는 대신 입력 조건에서 해 함수로 가는 연산자 Gθ를 근사한다.

Gθ : (u₀, b, λ, O) → û(x,t)
과학적으로 좋은 모델은 평균 오차가 작은 모델이 아니라, 정확성·물리적 허용성·시간 일관성·보정된 불확실성을 동시에 만족하는 모델이다.
Scientific validity = predictive accuracy ∧ physical admissibility ∧ temporal consistency ∧ calibrated uncertainty
02
Problem Definition

핵심 문제 정의

2.1 순방향 시뮬레이션

(u₀, b, λ) → u(t)

초기조건, 경계조건, 물성으로부터 미래 상태를 예측한다. 유체, 지진파, 난류, 상장, 플라스마, 우주론, 양자계가 대표 대상이다. 핵심은 특정 격자에서 한 번 맞추는 것이 아니라 서로 다른 조건과 해상도에서 재사용 가능한 해 연산자를 학습하는 데 있다.

2.2 역문제와 파라미터 추론

y = H(u, λ) + ε   ⇒   p(u, λ | y)

불완전하거나 잡음이 포함된 관측으로부터 숨겨진 상태와 파라미터를 복원한다. 강한 중력렌즈, 쌍성계, 펄서 광곡선, 미세중력렌즈, 산란 매질 복원이 여기에 속한다. 단일 점추정이 아니라 다중모드 사후분포와 시뮬레이션-실측 차이를 함께 처리해야 한다.

2.3 설계와 제어

z* = arg minz J(S(z))    subject to    C(S(z)) ≤ 0

광소자, RF 필터, 충돌기 빔, MRI 프로토콜, 양자 제어에서 목표 성능을 만족하는 설계 변수나 제어 입력을 찾는다. 미분 가능성, 제조 가능성, 안정성, 다목적 trade-off가 함께 고려된다.

2.4 과학 에이전트 워크플로

st+1 = T(st, at, ot),   at ~ πθ(at | st, mt)

에이전트는 문헌, 코드, 계산 도구, 시뮬레이터를 이용해 가설 설정, 유도, 계산, 비평, 검증을 반복한다. 최종 문장의 자연스러움보다 물리 모델 선택, 단위·경계조건 확인, 실행 가능한 코드, 실패 감지, 근거·불확실성 보고가 중요하다.

2.5 기초모델과 전이학습

Gθ(context, ut) → ut+Δt

서로 다른 물리계에서 하나의 모델을 사전학습하고 새로운 방정식이나 조건에 적은 적응 비용으로 전이시키는 문제다. 짧은 trajectory나 경계조건이 물리 prompt 역할을 하며, 모델은 문맥으로부터 지배 동역학을 추론한다.

03
Core Concepts

핵심 개념

Neural Operator

함수 공간 사이의 연산자 학습

유한차원 벡터 함수가 아니라 입력 함수에서 해 함수로 가는 연산자를 근사한다.

Gθ : X → Y
Physics-informed Learning

데이터와 PDE 잔차의 결합

데이터 손실, PDE 잔차, 경계조건을 결합하되 soft penalty의 불완전성을 인식한다.

L = Ldata + λPDELres + λBCLboundary
Equivariance

대칭성을 구조에 내장

회전, 병진, Lorentz 변환, 순열 대칭에 일관되게 반응하는 표현을 구성한다.

f(g·x) = g·f(x)
Generative Physics

분포 수준의 물리 상태 생성

Diffusion, flow matching, graph flow로 다중해와 불확실성을 표현한다.

dxt/dt = vθ(xt, t, c)
Temporal Consistency

시간 합성의 반군 일관성

직접 예측과 여러 단계 합성 예측이 동일한 동역학을 나타내야 한다.

St+s = St ○ Ss
Adaptive Memory

부분 관측에서 필요한 역사 선택

상태에 따라 과거 정보의 유효 범위를 동적으로 조절한다.

ht = Φ(ht-1, ot)
Differentiable Simulation

시뮬레이터를 통한 기울기 전파

Adjoint, implicit differentiation, sparse solver를 이용해 역설계와 제어를 수행한다.

∂J / ∂λ
Formal Verification

자연어에서 형식적 증명으로

설명과 수학적 구조를 분리해 평가하고, 형식증명기와 수치 인증을 결합한다.

Natural language → Formal object → Proof
04
Introduction

연구 패러다임의 진화

1단계물리 데이터 예측
2단계학습형 시뮬레이션
3단계역문제와 설계
4단계도구 사용 과학 에이전트
5단계검증 가능한 자율 과학 시스템

초기 연구는 입자 분류, 물질 특성 예측, 천체 시계열 분류와 같이 특정 데이터셋에서 물리량을 예측하는 데 집중했다. 이후 신경 연산자와 생성형 모델이 수치해석기를 근사하면서, 목표는 단일 태스크 정확도에서 다양한 조건에 재사용 가능한 solution operator로 확장되었다.

현재의 중심은 자율 과학 시스템이다. AI가 문헌 검색, 코드 생성, 시뮬레이션, 결과 해석, 실험 설계, 반증과 검증까지 수행한다. Terminal-Bench Science, Stargazer, QMP-Bench, SCALAR, Plausible but Wrong은 이 단계의 실제 연구 수행 능력과 실패 양상을 평가한다.

핵심 질문은 “물리량을 얼마나 정확히 예측하는가?”에서 “새로운 조건에서 일관된 모델을 구성하고, 불확실성을 인식하며, 도구를 사용하고, 자신의 계산을 검증할 수 있는가?”로 이동한다.
05
Motivation & Background

연구 동기와 배경

Computational Cost

고충실도 시뮬레이션 비용

CFD, DFT, 양자 다체계, 우주론 계산은 반복 실험이나 역설계에 직접 사용하기 어렵다. 대리모델은 고비용 offline simulation을 빠른 online inference로 전환한다.

Ill-posedness

역문제의 비정칙성

여러 원인이 같은 관측을 만들 수 있고, 작은 잡음이 큰 파라미터 변화를 일으킨다. posterior sampling과 simulation-based inference가 필요하다.

Distribution Shift

관측 부족과 분포 이동

실험 데이터는 비싸고 불완전하며 특정 조건에 편향된다. partial observation, active sampling, uncertainty-aware transfer가 필수다.

Scientific Reliability

그럴듯하지만 잘못된 에이전트

실행 가능한 코드와 매끄러운 보고서가 물리적으로 잘못된 결론을 숨길 수 있다. 실패 감지와 독립 검증이 핵심 연구 문제가 된다.

속도만으로 충분하지 않은 이유

빠른 모델이 보존법칙을 위반하거나 장기 rollout에서 발산하면 과학적 의사결정에 사용할 수 없다. 따라서 정확도, 보존성, 안정성, 불확실성, 영역 외 일반화를 함께 평가해야 한다.

Reality gap = model discrepancy + sensor discrepancy + selection bias + unknown physics
06
Challenges

주요 난제

Plausible-but-wrong failure

코드가 정상 실행되고 적합도도 양호하지만 물리 파라미터나 과학 결론이 잘못되는 가장 위험한 실패다.

Long-horizon instability

한 단계 오차가 작아도 반복 적용 시 누적·증폭된다. 반군 일관성, Lyapunov 안정성, neural twin이 대응 전략이다.

Constraint–accuracy trade-off

hard constraint는 표현력을 제한할 수 있고, soft penalty는 제약 만족을 보장하지 못한다.

Extrapolation across regimes

상전이, bifurcation, 충격파, 희귀 사건에서는 작은 파라미터 변화가 질적으로 다른 해를 만든다.

Partial observability and memory

현재 프레임만으로 상태가 완전하지 않지만, 무조건 긴 history는 계산량과 과적합을 증가시킨다.

Simulation-to-real gap

센서 편향, 선택 효과, 미지의 외란, 불완전한 물리 모델 때문에 시뮬레이션 성능이 실측 성능으로 이어지지 않는다.

Evaluation incompleteness

단일 RMSE는 보존 위반, 시간 불일치, 파라미터 식별 오류, 과신, 실행 실패를 측정하지 못한다.

Computational scalability

미분 가능한 대규모 시뮬레이션은 메모리와 통신비용을 급격히 증가시킨다. 희소 연산과 adjoint가 중요하다.

장기 예측 오차의 직관

et+1 ≲ L·et + εt

동역학의 유효 Lipschitz 계수 L이 1보다 크면 작은 오차가 지수적으로 확대될 수 있다. 따라서 one-step accuracy만으로 장기 안정성을 판단할 수 없다.

07
Research Questions

핵심 연구질문

하나의 모델이 서로 다른 물리계를 학습할 수 있는가?

새로운 방정식, geometry, 경계조건에 zero-shot 또는 few-shot으로 적응하는 진정한 물리 기초모델이 가능한가?

모델이 동역학을 학습했는가, 템플릿을 기억했는가?

높은 테스트 성능이 실제 법칙 이해를 의미하는지, 데이터 패턴의 재사용인지 분리할 수 있는가?

생성형 PDE 해법은 과학적으로 정당한가?

유일해를 갖는 문제에서 분포 모델이 올바른 점분포로 수렴하는 조건은 무엇인가?

물리 제약은 어디에 삽입해야 하는가?

손실, 구조, 출력 투영, 샘플링 과정, 최적화기 중 어느 위치가 가장 안정적이고 확장 가능한가?

에이전트 비평은 언제 성능을 높이는가?

Critic의 능력, 오류 유형, Actor와의 비대칭성이 수정 성공률에 어떤 영향을 주는가?

더 많은 test-time compute가 더 나은 과학 추론을 보장하는가?

추가 토큰과 반복이 실제 탐색인지, 동일한 실패 루프의 반복인지 구분할 수 있는가?

자연어 추론을 검증 가능한 형식으로 변환할 수 있는가?

설명, 수식, 코드, 형식증명 사이에서 의미와 가정이 보존되는가?

모델 규모와 과학적 추론 능력은 동일한가?

검증 가능한 보상과 과학 데이터 설계가 단순 파라미터 규모보다 더 중요한가?

장기 예측에 필요한 메모리는 얼마인가?

상태별 Markov 불완전성에 따라 유효 history 길이를 동적으로 선택할 수 있는가?

학습형 시뮬레이터를 어떻게 인증할 것인가?

오차 한계, 보존성, OOD 감지, 불확실성 보정, 전문가 검토를 하나의 인증 체계로 결합할 수 있는가?

Approaches & Methods

주요 접근 방법

8.1 Neural Operator 계열

Fourier Neural Operator Kernel Neural Operator Schur Complement Operator Koopman Operator Deep Ritz Operator Continuous-time Operator Memory-augmented Operator

특정 격자의 값이 아니라 초기조건과 계수 함수에서 해 함수로 가는 연산자를 학습한다.

8.2 구조 보존 모델

û = PC(fθ(x))

허용 가능한 물리 상태 집합 C로의 projection 또는 correction을 통해 divergence-free, 질량·에너지 보존, Lorentz·rotation equivariance, Lie symmetry, Hamiltonian·Lyapunov 구조, inequality constraint를 만족시킨다.

8.3 생성형 시뮬레이션과 역추론

Diffusion, flow matching, graph flow, neural process, recurrent inference machine을 사용해 다중모드 posterior, 불확실성, 부분 관측 복원, 고차원 상태 생성을 처리한다. 핵심 과제는 생성 샘플의 물리적 허용성을 보장하는 것이다.

8.4 Hybrid Neural–Numerical Method

Hybrid solver = numerical backbone + learned closure / correction

Neural–MPM, neural Schur complement, local rollout, simulator-guided optimization, neural twin, differentiable sparse solver처럼 기존 수치해석기의 안정성과 신경망의 표현력을 결합한다.

8.5 Agentic Actor–Critic–Verifier

Actor초기 해답과 코드 생성
Critic오류와 누락 식별
Revision해답·코드 수정
Tool Check실행·수치 검증
Judge과학적 타당성 평가

8.6 Verifiable Reward Training

R = Rcorrect + Rconstraint + Rconsistency + Revidence

정답 여부뿐 아니라 제약 만족, 일관성, 근거 제시를 보상에 포함한다. Mat-Pref는 SFT와 GRPO를 결합해 재료 조성 추론에서 검증 가능한 보상 설계의 효과를 탐색한다.

8.7 Benchmark-centered Research

Benchmark대상핵심 평가
Stargazer천체물리 모델 적합도구 사용, 파라미터 복원, 실패 복구, 워크플로 수행

여러 물리계의 trajectory를 하나의 transformer에 학습하고, 짧은 과거 상태를 문맥으로 사용해 지배 동역학을 추론한다. 방정식 ID 대신 관측 trajectory 자체가 물리 prompt 역할을 한다.

Open Problems

미해결 문제

OP-01

Physics Foundation Model의 기준

새로운 방정식, 차원, geometry, 경계조건, 상전이에 대한 독립적 zero-shot 검증이 필요하다.

OP-02

통계적 적합과 과학적 정확성의 분리

낮은 residual이나 높은 likelihood가 올바른 물리 파라미터를 의미하지 않는다.

OP-03

인증 가능한 에이전트

독립 checker, constraint engine, uncertainty monitor, provenance log가 통합되어야 한다.

OP-04

불확실성의 분해

Aleatoric과 epistemic uncertainty를 구분하고 분포 이동에서 지식 부족을 감지해야 한다.

OP-05

다중 제약 충돌

질량, 에너지, 양성성, 안정성 제약이 충돌할 때 우선순위를 결정하는 일반 원리가 부족하다.

OP-06

인과적 세계모델

trajectory 예측을 넘어 intervention과 counterfactual을 안정적으로 처리해야 한다.

OP-07

Benchmark contamination

사전학습 데이터 누출을 피하기 위해 동적 문제 생성과 과정 기반 평가가 필요하다.

OP-08

대규모 미분 시뮬레이션

Adjoint, checkpointing, implicit differentiation, domain decomposition의 통합이 필요하다.

OP-09

인간–AI 책임 배분

AI 생성 가설, 코드, 수치 결과의 검증 의무와 학술 책임을 명확히 정의해야 한다.

OP-10

과학적 재현성

모델, 데이터, solver, seed, 하드웨어, 단위, 수치 허용오차를 완전하게 기록해야 한다.

Agent + independent checker + constraint engine + uncertainty monitor + provenance log

Future Directions

미래 연구 방향

11.1 Physics-native Agentic Stack

Scientific Agent = Planner + Symbolic Reasoner + Simulator + Data Analyst + Verifier + Memory

범용 LLM 위에 도구를 단순 연결하는 방식에서 벗어나, 각 계층이 독립적인 실패 감지와 provenance를 제공하는 물리 네이티브 에이전트 스택으로 발전한다.

11.2 Certified Physics Foundation Model

(û, σ, Cviolation, DOOD, Eevidence)

미래의 물리 기초모델은 예측값뿐 아니라 불확실성, 제약 위반, 분포 이탈 정도, 근거와 계산 이력을 함께 출력해야 한다.

11.3 Diagnostic-first Learning

Semigroup Test

시간 분할과 합성에 대한 일관성을 검사한다.

Conservation Test

질량·에너지·운동량 보존 위반을 정량화한다.

Bifurcation Test

질적 상태 전환과 임계점을 보존하는지 확인한다.

Symmetry Test

회전·병진·Lorentz 변환에 대한 equivariance를 측정한다.

Causal Test

개입과 반사실 질의에 대한 안정성을 평가한다.

Calibration Test

예측 불확실성과 실제 오차의 일치도를 검증한다.

11.4 Closed-loop Co-Scientist

Hypothesis가설 생성
Design실험 설계
Measure관측·실행
Infer추론·모델 갱신
Critique반증·새 가설

11.5 Formal–Numerical Co-verification

Trustworthy result = formal correctness ∧ numerical reliability

형식증명기는 수학적 유도와 논리를 검증하고, numerical certificate는 부동소수점 계산, 근사 오차, solver 수렴성을 검증하는 이중 구조가 필요하다.

11.6 Active Scientific Data Generation

x* = arg maxx [uncertainty(x) + scientific value(x) − simulation cost(x)]

대규모 무작위 생성보다 모델이 가장 모르는 레짐, 과학적 가치가 높은 영역, 실험 비용이 감당 가능한 조건을 선택하는 능동 샘플링이 중요해진다.

12
Synthesis

종합 결론

AI4Physics의 핵심 변화는 “물리를 빠르게 예측하는 AI”에서 “물리법칙 아래에서 추론하고 행동하며 스스로 검증되는 AI”로의 전환이다.

과거의 목표는 주로 예측 오차 최소화였다.

minθ ||ûθ − u||²

앞으로는 다목적 과학적 타당성 최적화로 확장된다.

minθ [ Lprediction + λ₁Lphysics + λ₂Lconsistency + λ₃Lcalibration + λ₄Lverification ]
Principle 01

정확도는 충분조건이 아니다

좋은 적합이 잘못된 파라미터와 인과 설명을 숨길 수 있다.

Principle 02

물리법칙은 기본 구조다

부가 정규화가 아니라 상태공간과 행동공간을 정의해야 한다.

Principle 03

반증 능력이 핵심이다

답 생성보다 실패 발견, 계산 검증, 새 실험 설계가 중요하다.

장기적 종착점은 하나의 거대한 예측모델이 아니다. 기초모델, 수치해석기, 형식검증기, 실험 제어기, 인간 전문가가 결합된 검증 가능한 과학 운영체제에 가깝다.
