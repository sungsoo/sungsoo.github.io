Rethinking Temporal Knowledge Graph Representation Learning:
From Entities to Evolutionary Event-Centric Clusters

Temporal Knowledge Graph는 사건의 집합인데, 왜 대부분의 모델은 사건을 다시 entity와 relation으로 분해한 뒤 entity만 연결해 왔을까. HEART는 이 질문을 뒤집어 event를 직접 node로 만들고, 사건 사이의 heterogeneous pairwise correlation과 high-order cluster, 그리고 cluster의 시간적 진화를 하나의 계층적 그래프로 학습한다.

01 · The modeling question

Temporal Knowledge Graph의 기본 단위는 event인데, 학습의 중심은 entity였다

TKG의 한 사건은 (s, r, o, t) quadruple이다. subject와 object entity, relation, timestamp가 하나의 사건을 이룬다. 그럼에도 기존 representation learning은 사건을 entity와 relation으로 분해하고, entity를 node, relation을 edge로 둔 “primary graph”에서 representation을 학습하는 데 집중했다.

GNN 계열은 entity의 pairwise structural dependency를 message passing으로 학습한다. 더 최근의 방법은 community, entity group, hypergraph, evolutionary cluster 같은 derived structure를 추가해 reachable하지 않은 entity 사이의 high-order correlation까지 모델링한다. 하지만 저자들의 문제 제기는 단순하다. event 자체 사이의 상관관계는 어디에 있는가?

논문은 event가 TKG의 core constituent임에도 기존 연구가 event-event correlation을 체계적으로 모델링하지 않았다고 주장한다. 사건은 shared entity를 통해 직접 연결될 수도 있고, entity를 공유하지 않아도 representation space에서 의미적으로 가까울 수 있으며, 여러 사건이 하나의 고차원적 pattern을 만들고 이 pattern이 시간에 따라 다른 pattern으로 이동할 수도 있다.

Source factHEART의 저자들은 이를 TKG 최초의 event-centric 접근이라고 명시한다. 논문의 기여는 새로운 event graph, multi-step evolutionary clustering, cross-temporal unsupervised alignment, event-cluster self-supervision, learnable sparsification을 하나의 event prediction architecture로 결합하는 데 있다.

02 · Figure 1

러시아-우크라이나 전쟁 이후의 에너지 재편은 왜 entity graph만으로 충분하지 않은가

페이지 2의 Figure 1은 논문의 동기를 사건 수준에서 보여준다. 2022년 2월 러시아-우크라이나 전쟁 발발(Event A) 이후 유럽연합과 미국이 러시아 에너지 의존을 줄이는 사건(Events B, C)이 발생한다. 이어 러시아-인도 할인 원유 계약(Event D), 카타르-독일 가스 공급 계약(Event E), 러시아-중국 가스 공급 계약(Event F)이 이어진다.

여기에는 서로 다른 종류의 correlation이 겹친다. A-B와 A-C처럼 entity를 공유하거나 직접적으로 이어지는 pairwise relation이 있고, B-E처럼 사건의 당사자가 완전히 동일하지 않아도 의미적으로 가까운 correlation이 있다. B와 C는 “러시아 에너지 의존 축소”라는 high-order pattern을 만들고, D·E·F는 “대체 혹은 재편된 에너지 공급”이라는 또 다른 pattern을 형성한다. 첫 pattern의 변화가 두 번째 pattern으로 이어진다.

①

Co-entity correlation

두 event가 subject/object entity를 하나 이상 공유한다. 관측 가능한 구조적 연결이다.

②

Proximity correlation

entity를 공유하지 않더라도 learned event representation에서 가까운 kNN이면 edge를 만든다.

③

High-order correlation

여러 event가 하나의 soft cluster에 동시에 속하며, cluster 자체가 시간에 따라 align되고 진화한다.

Analysis이 예시는 “전쟁 → 에너지 정책 변화”라는 인과를 자동으로 증명하는 장치가 아니다. HEART가 실제로 만드는 것은 causal graph가 아니라 event representation과 cluster evolution이다. Figure 1의 역할은 entity 공유 여부만으로는 설명되지 않는 사건 간 구조가 존재한다는 모델링 직관을 제공하는 데 있다.

03 · Related work

TKG representation과 event representation은 따로 발전해 왔다

TKG representation learning

TeMP, RE-GCN, TiRGN 같은 방법은 RGCN과 GRU/RNN을 결합해 graph structure와 temporal dependency를 함께 다룬다. distant entity interaction을 layer stacking으로 처리하면 over-smoothing이 생길 수 있어 CluSTeR, TITer, LogCL, DyMemR처럼 rule/path/subgraph를 만드는 접근도 등장했다.

그 다음 단계는 derived structure이다. EvoExplore는 dynamic community를 만들고, GTRL은 entity group, DHyper는 hypergraph, DECRL은 evolutionary clustering을 이용해 high-order entity correlation과 temporal evolution을 포착한다. HEART는 바로 이 계열과 가장 직접적으로 경쟁하지만 cluster의 구성 단위를 entity에서 event로 바꾼다.

Event representation learning

intra-event 방법은 predicate와 argument를 aggregate/concatenate해 MLP로 encode하거나 NTN, CNN, Transformer, BERT 등을 사용해 event 내부 의미를 압축한다. EVENTCOMP, Predicate Tensor Model, SWCC가 이 범주에 속한다.

inter-event 방법은 co-occurrence graph나 explicit temporal/causal relation, external knowledge를 사용한다. GraphBERT는 event graph에서 GNN propagation을 수행하고, NG와 MCPredictor는 원문이나 외부 지식을 이용해 event representation을 보강한다. 논문은 이런 방법이 predefined/external relation에 의존하고 latent high-order event correlation과 그 temporal evolution을 충분히 모델링하지 않는다고 본다.

AnalysisHEART의 위치는 두 연구 흐름의 교차점이다. TKG 쪽에서 발전한 temporal graph reasoning과 event representation 쪽의 event-level composition을 결합하되, event cluster의 multi-step evolution을 TKG prediction objective와 직접 연결한다.

04 · Preliminaries

Primary graph → Event graph → Event cluster graph의 세 층을 명시적으로 정의한다

Definition 1 — Temporal Knowledge Graph
G = {(s, r, o, t) | s,o ∈ E, r ∈ R, t ∈ T}

시점 t의 사건 집합은 G^t로 표기한다.

Definition 2 — Primary Graph
G_p^t = (V_p^t, E_p^t)

node는 entity, edge는 relation이다. 기존 TKG representation learning의 기본 graph이다.

Definition 3 — Event Graph
G_x^t = (V_x^t, E_x^t)

node가 event이고 edge가 event 사이의 heterogeneous pairwise correlation이다.

Definition 4 — Event Cluster Graph
G_c^t = (V_c^t, E_c^t)

node는 event cluster, edge는 cluster 사이의 latent correlation이다. event cluster가 high-order event correlation을 표현한다.

event prediction task는 query (s, ?, o, t)에서 subject와 object, 과거 G^{1:T-1}이 주어졌을 때 가능한 relation의 조건부 확률 p(r̂ | s,o,G^{1:T-1})을 예측한다. 즉 link prediction의 relation slot을 temporal history를 사용해 채우는 문제이다.

05 · Architecture overview

HEART는 세 단계의 graph를 따라 event correlation을 점점 더 높은 차수로 올린다

페이지 4 Figure 2를 개념적으로 재구성한 흐름이다. 원 논문의 정량 chart를 복제한 것이 아니다.
Primary graph
entities + relations
→
Event graph
events + co-entity/proximity edges
→
Event clusters
soft overlap + temporal alignment
→
Cluster graph
latent edges + message passing

각 timestamp에서 relation-aware RGCN이 entity/relation representation을 갱신한다. relation-aware tensor event encoder가 (s,r,o)를 하나의 event vector로 만든다. event graph construction은 co-entity와 proximity edge를 붙인다. fuzzy c-means가 overlapping event cluster를 만들고, Hungarian matching이 과거 cluster와 현재 cluster를 정렬한다. self-supervised cluster optimization과 learnable sparsification이 cluster graph를 정제한다.

cluster-level 정보는 membership matrix를 통해 event로 되돌아가고, event에서 entity representation으로 역전파된다. time residual gate는 이전 timestamp representation과 현재 input을 섞고, attentive temporal encoder가 여러 timestamp의 entity/relation history를 position-enhanced self-attention으로 통합한다. 마지막에는 ConvTransE decoder가 relation probability를 예측한다.

06 · Event graph construction

Event를 단순히 s+r+o로 합치지 않고 relation-aware tensor interaction으로 encode한다

먼저 primary graph에서 RGCN이 structural dependency를 학습한다. object o의 다음 layer representation은 incoming (s,r) neighbor의 h_s + h_r를 degree-normalized aggregation하고 self-loop h_o를 더한 뒤 RReLU를 통과한다.

h_o^{t,l+1} = RReLU( (1/d_o) Σ W_1(h_s^{t,l}+h_r^{t,l}) + W_2 h_o^{t,l} ) — Eq. (1)

초기 entity representation은 in-degree가 같은 entity끼리 동일하게 배정해 update를 빠르게 하고, relation은 random initialization한다. relation representation은 해당 relation과 연결된 entity representation과 이전 시점 relation representation을 mean-pooling해 갱신한다.

event encoder의 핵심은 3-way tensor T이다. 같은 entity pair라도 relation이 다르면 사건 의미가 완전히 달라질 수 있으므로 subject-relation과 object-relation interaction을 별도로 계산한다.

v_{s,i}=Σ_{j,k} T_{ijk} h_{s,j} h_{r,k},   v_{o,i}=Σ_{j,k} T_{ijk} h_{o,j} h_{r,k} — Eq. (2)
x = W_s v_s + W_o v_o — Eq. (3)

이렇게 만들어진 x가 event graph의 node가 된다. event 사이에는 두 종류 edge를 만든다.

(x_i^t,x_j^t) ∈ E_coe^t ⇔ E(x_i^t) ∩ E(x_j^t) ≠ ∅ — Eq. (4)
(x_i^t,x_j^t) ∈ E_prox^t ⇔ x_j^t ∈ kNN(x_i^t) ∨ x_i^t ∈ kNN(x_j^t) — Eq. (5)

E_x^t = E_coe^t ∪ E_prox^t로 합쳐 heterogeneous event graph를 만들고, 다시 RGCN을 적용해 local structural/semantic event correlation을 학습한다.

07 · Event-aware multi-step evolutionary clustering

Event는 하나의 cluster에만 속하지 않는다. Soft membership을 유지한 채 시간축에서 cluster identity를 맞춘다

한 event는 여러 high-order pattern에 동시에 참여할 수 있으므로 hard clustering 대신 fuzzy c-means를 사용한다. membership U_{i,j}^{t,m}은 event x_i^t가 cluster centroid μ_j^t에 속하는 정도를 표현한다.

J = Σ_i Σ_j U_{i,j}^{t,m} (1 - cos(x_i^t, μ_j^t)),   Σ_j U_{i,j}^{t,m}=1 — Eq. (6)

cluster representation은 membership-weighted event sum으로 만들고, membership은 cosine similarity와 fuzzy smoothing parameter m>1로 계산한다.

c_j^t = Σ_i U_{i,j}^{t,m} x_i^t — Eq. (7)

문제는 timestamp가 바뀌면 event에 persistent identifier가 없고 cluster index도 임의라는 점이다. HEART는 event cluster에 속한 entity distribution을 이용해 과거와 현재 cluster를 align한다. event-to-entity mapping matrix M^t와 entity occurrence normalization D^{-1}를 사용한다.

H^t = (U^t)^T M^t D^{-1} — Eq. (8)

과거 cluster와 현재 cluster entity distribution의 cosine similarity로 affinity matrix를 만든다.

A_{j,k} = cos(H_j^{t-1}, H_k^t) — Eq. (9)

Hungarian algorithm이 one-to-one maximum-similarity matching을 다항 시간에 구한다. 이렇게 얻은 permutation π^τ로 현재 cluster와 모든 aligned historical cluster를 평균해 multi-step representation을 만든다.

c̃_j^t = (1/N_t)( c_j^t + Σ_{τ=1}^{t-1} c_{π^τ(j)}^τ ) — Eq. (10)

마지막으로 aligned cluster가 시간에 따라 급격히 흔들리지 않도록 cosine distance 기반 temporal smoothness loss를 둔다.

L_temporal = Σ_{τ=1}^{t-1} Σ_j (1 - cos(c̃_j^τ, c̃_j^t)) — Eq. (11)
AnalysisDECRL처럼 entity cluster는 persistent entity ID를 이용해 시점 간 대응을 만들기 쉽다. event cluster는 동일 event ID가 다음 timestamp에 존재하지 않는다. HEART가 entity distribution을 intermediate alignment key로 사용한 이유가 여기에 있다.

08 · Event cluster graph message passing

Cluster를 만든 뒤에는 어떤 cluster끼리 실제로 상호작용할지 다시 학습한다

self-supervised optimization은 비슷한 cluster의 cohesion을 높이고 다른 cluster의 differentiation을 키우려는 장치이다. 먼저 Euclidean cluster distance L과 inverse-distance weight K를 계산한다.

L_{j,k}=||c̃_j^t-c̃_k^t||_2,   K_{j,k}=α/L_{j,k} — Eq. (12)

cosine similarity F로 similarity adjustment S를 만든다.

F_{j,k}=cos(c̃_j^t,c̃_k^t),   S_{j,k}=β(1-F_{j,k}) — Eq. (13)

distance와 similarity adjustment를 합쳐 cluster representation을 shift한다.

ĉ_j^t = c̃_j^t + Σ_k K_{j,k} S_{j,k} c̃_k^t — Eq. (14)

shift가 원 representation의 방향을 과도하게 바꾸지 않도록 self-supervised cosine loss를 둔다.

L_self-supervised = Σ_i (1 - cos(ĉ_i^t,c̃_i^t)) — Eq. (15)

cluster graph edge는 implicit correlation encoder가 만든다. 두 cluster를 concatenate한 뒤 MLP와 ReLU로 latent relation z_{i,j}를 만들고, convolution+sigmoid로 edge intensity q_{i,j}를 0–1 사이에 둔다. learnable threshold κ보다 작은 edge는 0으로 만든다.

q̂_{i,j}^t = q_{i,j}^t if q_{i,j}^t > κ, otherwise 0 — Eq. (16)

남은 edge intensity를 weight로 message를 aggregate한다.

b_i^t = Σ_{i≠j} q̂_{i,j}^t z_{i,j}^t,   ĉ̂_i^t = φ(b_i^t ; ĉ_i^t) — Eq. (17)

그 뒤 fuzzy membership matrix를 이용해 cluster-level message를 event로 내리고 x_i'^t = Σ_j U_{i,j}^{t,m} ĉ̂_j^t로 갱신한다. event construction을 역으로 적용해 entity representation도 업데이트한다.

09 · Temporal integration and event prediction

Event-centric 구조가 최종적으로 entity와 relation representation을 다시 바꾼다

HEART가 event를 직접 예측하는 별도 decoder를 쓰는 것은 아니다. event graph와 cluster graph가 entity/relation representation을 개선하고, time residual gate와 attentive temporal encoder가 여러 시점의 representation을 통합한다. 저자들은 이 두 component의 상세식은 기존 연구 [7,39,40]를 참조하고, position-enhanced self-attention으로 final representation H를 얻는다고 설명한다.

decoder는 ConvTransE이다. entity pair를 convolution한 feature와 relation matrix를 곱해 가능한 relation의 확률을 예측한다.

p(r̂ | s,o,G^{1:T-1}) = σ( H_r · ConvTransE(ē_s,ē_o) )

TKG prediction loss는 multi-label binary cross entropy 형태이다.

L_TKG = -(1/N_S) Σ_i Σ_j [ y_{i,j} log p_{i,j} + (1-y_{i,j}) log(1-p_{i,j}) ] — Eq. (18)

전체 objective는 prediction, temporal smoothness, self-supervised cluster shift의 weighted sum이다.

L = (1-λ-γ)L_TKG + λL_temporal + γL_self-supervised,   λ,γ∈[0,1], λ+γ<1 — Eq. (19)

TITer · EvoExplore · GTRL · DHyper · DECRL

path, dynamic community, entity group, hypergraph, evolutionary entity cluster를 이용해 distant/high-order correlation을 학습한다.

TiRGN은 저자들이 사용하는 SOTA GNN baseline이고, DECRL은 가장 강한 derived-structure baseline이다. HEART와 DECRL의 차이는 부록에서 별도로 강조된다. DECRL은 entity-level evolutionary cluster이고 persistent entity ID가 있다. HEART는 event graph/event cluster graph를 직접 만들고 entity distribution 기반 multi-step alignment가 필요하다. 또 DECRL은 adjacent timestamp smoothness 중심인 반면 HEART는 multi-step temporal loss와 cluster-level self-supervised objective를 추가한다.

19 · Hyperparameter sensitivity

가장 민감한 두 축은 cluster 수와 history window 길이이다

페이지 12 Figure 4는 ICEWS14에서 하나의 hyperparameter만 바꾸고 나머지는 Table 7의 값을 고정해 sensitivity를 측정한다. N_c는 16까지 증가할수록 좋아지다가 이후 급격히 떨어진다. cluster가 너무 적으면 high-order correlation을 충분히 분리하지 못하고, 너무 많으면 cluster graph message passing에 noise가 늘어난다는 설명이다.

N_window는 12에서 최적이다. window가 너무 짧으면 역사 정보가 부족하고 너무 길면 redundant data가 많아진다. 반면 HEART layer 수, α, kNN neighbor k는 넓은 범위에서 performance fluctuation이 작다.

Source fact저자들은 HEART의 primary performance driver가 N_c와 N_window라고 결론내리고, N_layer, α, k는 상대적으로 non-critical하다고 보고한다.

20 · Limits and interpretation

HEART의 성공 조건은 event density와 temporal resolution에 묶여 있다

Coarse time granularity. 가장 명확한 source-supported limitation은 WIKI/YAGO이다. 연 단위 timestamp에서는 HEART가 DECRL보다 MRR −0.53%, −1.16% 낮다. 논문 스스로 fine-grained event correlation을 포착할 시간 정보가 부족하기 때문이라고 설명한다.

Quadratic event graph cost. event graph construction은 O(N_x²D) 항을 가진다. event가 한 timestamp에 매우 많을수록 event-centric pairwise structure의 비용이 커진다. 논문은 memoization을 쓰지만 scalability experiment를 별도로 제시하지 않는다.

Training overhead. ICEWS14에서 HEART training time은 5285.58초로 DECRL 4066.57초보다 길다. inference는 빠르지만 학습비용이 사라지는 것은 아니다.

Benchmark family. 7개 dataset은 TKG community에서 널리 쓰이지만 ICEWS 계열 정치 사건이 네 개이고, GDELT도 event/news 기반이다. WIKI/YAGO는 coarse-grained counterexample을 제공한다. 다른 산업/과학 event graph에서 동일한 improvement가 유지되는지는 이 논문이 직접 검증하지 않는다.

“First event-centric” claim. 저자들은 TKG에서 HEART를 최초 event-centric approach라고 명시한다. 다만 related work에는 event representation/event graph 연구가 존재한다. novelty의 정확한 범위는 “TKG event prediction 안에서 event graph + evolving event-cluster graph를 중심 representation mechanism으로 사용하는 것”으로 읽는 편이 안전하다.

InferenceHEART의 더 넓은 의미는 entity를 버리는 데 있지 않다. event representation을 intermediate computational object로 도입한 뒤 그 correlation을 학습하고 다시 entity/relation representation으로 되돌린다. 즉 “entity-centric vs event-centric”는 완전한 대체라기보다 어느 수준의 구조를 먼저 모델링할 것인가에 대한 inductive-bias 선택이라고 볼 수 있다.

21 · Key takeaways

핵심 정리

Event를 직접 node로 만든다.entity graph에서 놓치기 쉬운 event-event pairwise correlation을 co-entity와 proximity edge로 명시한다.
High-order correlation은 soft event cluster로 표현한다.fuzzy c-means가 event의 overlapping membership을 허용한다.
Cluster identity를 entity distribution으로 시간축에 align한다.persistent event ID가 없어도 Hungarian matching으로 multi-step evolution을 추적한다.
Cluster graph도 다시 sparsify하고 message passing한다.self-supervised optimization과 learnable threshold가 latent inter-cluster edge를 정제한다.
7개 dataset 평균에서는 강한 gain을 보인다.runner-up 대비 평균 MRR +3.89%, Hits@1 +8.14%, Hits@3 +5.97%, Hits@10 +6.92%이다.
하지만 모든 cell에서 승리하지 않는다.ICEWS14 Hits@10, WIKI MRR, YAGO MRR에서는 DECRL이 더 높다.
Temporal resolution이 중요하다.year-level WIKI/YAGO의 상대적 약세와 sensitivity의 history-window 효과가 event evolution modeling의 조건을 보여준다.
성능 대가는 더 복잡한 구조와 학습시간이다.event graph의 quadratic term과 ICEWS14 training overhead가 존재한다.
