THE CENTRAL QUESTION

Attention이 없는 모델에서도 왜 맨 앞 토큰이 깊은 층의 정보 흐름을 독점할 수 있는가?

PART 01 · DEFINITION
01

정의: 상태, 토큰 표현, attention sink를 분리한다

LFM은 Liquid AI의 모델군이고, Mamba는 입력 의존 선택성을 가진 상태공간 아키텍처다. LFM2는 입력 의존 gated short convolution과 일부 GQA를 결합하며, LFM3는 별도의 tri-hybrid 제품군이다. LFM=LTC=LNN=Mamba라는 동일시는 틀리며, 이번 Mamba·Mamba-2 분석을 모든 LFM 세대에 소급해서는 안 된다.

Recurrent state는 과거 입력을 압축한 내부 메모리이고, token representation은 층을 거치며 갱신되는 각 위치의 표현이다. 이 논문은 상태 용량 자체보다 후자의 깊이 방향 동역학을 본다. Attention sink는 여러 후속 위치의 유효 상호작용이 한 위치—여기서는 첫 토큰—에 과도하게 집중되는 현상이다. Mamba에는 softmax attention head가 없으므로 저자들은 S6의 입력–출력 전개로 얻은 hidden attention matrix를 사용한다.

사실원 논문은 첫 토큰 sink를 채널별 hidden attention으로 정의한다. Transformer의 attention 확률과 동일한 객체가 아니다. 따라서 “Mamba에도 attention layer가 있다”는 뜻으로 읽으면 안 된다.
PART 02 · PROBLEM FORMULATION
02

문제 정의: 효율성과 표현 붕괴를 동시에 제약한다

긴 이력, 낮은 비용, 높은 정확도를 함께 달성하려는 목표는 여전히 다목적 최적화다. 이번 연구는 여기에 토큰 다양성 보존과 위치 독점 억제를 추가한다.

maximize Quality(θ) subject to p95 ≤ L, memory ≤ M, energy/task ≤ E, retrieval ≥ R, and sink concentration ≤ S

표준 full attention의 prefill은 길이에 대해 이차 연산이며 KV cache는 선형으로 증가하고, decode 한 토큰의 attention 연산은 이력 길이에 선형이다. 고정 상태 순수 SSM은 총 선형 연산과 길이에 독립적인 순환 상태를 갖는다. 그러나 고정 상태의 계산 효율은 깊은 층에서 표현이 한 위치로 수렴하지 않는다는 보장이 아니다.

PART 03 · CORE CONCEPTS
03

핵심 개념: 선택적 상태식에서 구면 위 흐름으로

Selective SSM

ht = Ātht−1 + B̄txt,   yt = Ctht

선택성은 입력마다 무엇을 쓰고, 잊고, 읽을지 조절한다. 추론 중 가중치를 학습한다는 뜻이 아니다. 순환 상태 크기가 문맥 길이에 독립이라는 말 역시 무한한 정보를 완전 보존한다는 뜻이 아니다.

Hidden interaction matrix

상태를 제거해 출력을 전개하면 현재 토큰 yl은 과거 토큰들의 가중 합 형태로 쓸 수 있다. 하지만 계수 Alj(x)는 softmax scalar가 아니라 채널별 대각 성분을 가진 입력 의존 행렬이다. 양수성과 definiteness가 자동으로 성립하지 않으므로, Transformer 동역학에 쓰던 monotone-system 도구를 그대로 적용할 수 없다.

Flow map on a sphere

RMS normalization을 반영해 각 토큰을 단위 구면 위의 점으로 보고, 층 깊이를 연속시간으로 보낸다. 저자들의 invariant box는 궤적이 머무는 고차원 영역을 만들고, sharp exit-time argument는 그 영역을 벗어날 수 있는 조건을 통제해 유효한 부호 구조를 회복한다.

해석메모리 용량만이 아니라 표현 공간의 attractor geometry가 장기 정보 접근성을 결정한다. 정보가 상태에 남아도 토큰 표현이 같은 방향으로 몰리면 서로 다른 증거를 구별하는 readout이 약해질 수 있다.
PART 04 · INTRODUCTION
04

도입: “Attention-free”가 “집중-free”를 뜻하지 않는다

Mamba 연구는 attention의 계산 병목 없이 content-aware sequence modeling을 달성하는 데서 출발했다. 그러나 효율적인 recurrence도 위치별 영향력이 균등하다는 보장은 없다. 첫 토큰은 causal ordering에서 과거 토큰을 갖지 않는 특수한 경계 조건이고, 이 비대칭이 깊이에 따라 증폭될 수 있다.

새 논문은 이를 세 단계로 연결한다. 첫째, 첫 토큰의 가능한 equilibrium과 limit point를 분류한다. 둘째, 일반적인 초기 조건에서 후속 토큰이 ±x₁로 지수 수렴함을 보인다. 셋째, 실제 Falcon-Mamba-7B에서 첫 위치 sink score가 층 깊이에 따라 증가하는지 확인한다.

저자 주장논문은 이를 SSM에서 attention sink가 나타난 첫 관측이라고 표현한다. 다만 검증은 170개의 길이 16 표본과 채널 부분표본에 기반하며, 장문 생성·검색·agent 성공률의 인과 효과를 직접 측정하지 않았다.
PART 05 · MOTIVATION & BACKGROUND
05

필요성과 배경: 연산자에서 기억의 위상으로

2023년 최초 공개된 Mamba 원논문과 2024년 Mamba-2는 본 글의 배경 연구다. 전자는 입력 의존 선택성과 hardware-aware scan을, 후자는 structured state-space duality를 통해 SSM과 attention의 수학적 연결을 제시했다. Falcon-Mamba-7B도 2024년 공개된 배경 기술보고서다.

2025–2026년 연구 흐름은 빠른 연산자 자체에서 장거리 회수, 상태 추적, 음의 고유값, hybrid 배치, 양자화 안정성, serving 메모리와 해석 가능성으로 이동했다. 이번 연구는 여기에 깊이에 따른 토큰 공간의 수렴을 더한다. 이는 “무엇을 저장할 것인가”와 “저장된 정보를 어떤 위치가 대표하게 되는가”가 서로 다른 문제임을 보여준다.

계산 관점

선형시간 scan과 고정 크기 state가 throughput·memory 측면의 이점을 제공한다.

정보 관점

유한 state는 정보를 압축하므로 정확 회수와 state tracking 사이에 trade-off가 생긴다.

동역학 관점

깊이가 늘며 표현이 attractor에 모이면 token diversity와 위치별 영향력이 바뀐다.

시스템 관점

CPU/GPU/NPU kernel, precision, sequence length가 이론적 현상의 실제 영향도를 조절한다.

PART 07 · RESEARCH QUESTIONS

연구 질문: 첫 위치의 이점은 언제 유용하고 언제 해로운가

  1. 동일 state memory에서 어떤 정보를 보존해야 하며, token-space diversity는 어느 수준 이상 유지해야 하는가?
  2. 첫 토큰 attraction과 정확한 장거리 회수 성능 사이에 단조 관계가 있는가, 아니면 요약에는 유용하고 key-value 회수에는 해로운가?
  3. 최소 attention 비중과 배치가 sink concentration을 제어하면서 Mamba의 memory 이점을 유지할 수 있는가?
  4. 음의·복소 고유값, MIMO state, normalization, residual scaling이 attractor 구조를 어떻게 바꾸는가?
  5. 양자화 오차가 층을 거치며 attraction을 강화하거나 완화하는가?
  6. 합성 sink score가 실제 agent 성공률, 근거 회수율, 오류 복구율, 성공 작업당 Joule과 연결되는가?
열린 질문첫 토큰을 단순히 제거하거나 약화하는 것이 답은 아니다. BOS·delimiter·system prompt가 유용한 global anchor 역할을 할 수도 있으므로, 집중의 크기뿐 아니라 그 집중이 어떤 정보와 작업을 지원하는지를 측정해야 한다.
PART 08 · APPROACHES / METHODS
08

접근법: 이론, 단순화 실험, pretrained 관측의 삼각측량

1. S6를 토큰 간 행렬 상호작용으로 전개

저자들은 recurrent hidden state를 제거해 각 출력 토큰을 이전 토큰들의 입력 의존 행렬 가중 합으로 나타낸다. RMS normalization과 skip connection을 반영한 연속시간 한계는 단위 구면의 tangent space에 투영된 flow가 된다.

2. Limit points와 exponential attraction

첫 토큰의 equilibrium을 분류하고, 적절한 대칭성·양의 정부호·각도 조건 아래 후속 토큰이 ±x₁로 지수 수렴함을 증명한다. 더 강한 positive-angle 조건에서는 하나의 cluster인 x₁로 정렬된다. 시간 의존 파라미터가 극한값으로 지수 수렴하는 경우에도 일반화를 제시한다.

3. 수치 simulation

랜덤 파라미터의 연속시간 시스템에서 100개 첫-token 초기화 중 94개가 좌표 단위벡터 ±ed로 수렴했다. 별도의 32-token 및 16-token sequence simulation에서도 후속 토큰 clustering을 시각화했다. 이는 실제 모델 성능이 아니라 정리 조건하의 수치 예시다.

4. 단순화한 Mamba-2

shared-weight block에서 causal convolution, input/output projection, activation, inner residual을 제거하고 64개 sequence를 처리했다. 첫 토큰의 non-near-zero 성분이 하나뿐인지 10−4 threshold로 측정했다. 저자들은 다수 sequence가 1-element representation으로 수렴했다고 보고한다.

5. Falcon-Mamba-7B

길이 16인 170개 표본, 각 층의 4096 channels 중 200개 균등 표본을 사용했다. first-token 중요도가 ε=0.3을 넘는 채널 비율을 layer-wise sink rate로 정의했다. 저자 보고상 first-token sink score는 깊이에 따라 증가하고 마지막 층에서 지배적이었다.

조건GPU, precision, batch latency, 전력은 보고되지 않았다. 이 연구는 시스템 benchmark가 아니라 동역학 분석이며, Falcon-Mamba 결과도 출력 품질이나 장문 context generalization을 직접 비교하지 않는다.
PART 09 · KEY APPLICATIONS
09

핵심 응용: 진단에서 sink-aware 설계까지

장문·로컬 RAG 진단

검색된 증거 위치별 hidden contribution과 first-token concentration을 함께 계측해 “상태에 저장됨”과 “출력에서 사용됨”을 구분한다.

스트리밍 분석

센서·음성 stream에서 BOS anchor의 영향이 시간이 지나며 drift하는지 관측하고 reset 정책을 설계한다.

온디바이스 보조

저정밀·긴 세션에서 sink score, retrieval accuracy, p95 latency, energy/task를 같은 실기기 시험에 넣는다.

Hybrid architecture search

attention layer를 sink가 임계치를 넘는 깊이에 배치하는 hardware-in-the-loop 탐색을 검증한다.

연구 제안ETRI/Physical AI에서는 센서 상태 추적, 로봇 고수준 계획, 엣지 운영지능의 장기 세션을 대상으로 첫 위치·최근 위치·외부 memory의 기여도를 분리 측정할 수 있다. 다만 이는 연구 제안이며, 저수준 제어 안전성은 별도 formal verification과 실기기 fail-safe가 필요하다.

PART 10 · OPEN PROBLEMS
10

미해결 문제: 관측된 sink가 언제 실패를 만든다

  • 과제별 유한 상태 한계: first-token attraction이 정보 압축의 원인인지 부산물인지 분리되지 않았다.
  • 망각 탐지: sink score 상승이 특정 증거의 망각과 일치하는지 token-level ground truth가 필요하다.
  • 장기 세션 drift/reset: 길이 16 관측을 수만 token streaming에 일반화할 수 없다.
  • 공정 비교: 동일 데이터·파라미터·quantization·kernel에서 Transformer, Mamba, hybrid를 비교해야 한다.
  • 개입 가능성: 첫 토큰을 교체·복제·dropout했을 때 sink와 성능이 함께 움직이는 causal test가 없다.
  • 한국어 전문업무: 조사·상담·설비 운용에서 긴 문서 근거 회수와 안전한 오류 복구가 검증되지 않았다.

단일 sink score는 설명 변수일 뿐 운영 지표가 아니다. 정확도·근거 회수율·calibration·에너지와 함께 볼 때만 의미가 있다.

PART 11 · FUTURE DIRECTIONS
11

향후 방향: 기억의 크기와 방향을 함께 설계한다

계층형 기억

압축 state + 필요한 구간 attention + 외부 증거 memory를 결합하고, first-token concentration이 높아질 때 최근 증거 또는 외부 memory로 read path를 전환한다. 이는 제안이며 논문의 실험 결과가 아니다.

적응형 예산

모든 token에 같은 memory budget을 쓰지 않고, retrieval uncertainty·sink concentration·state drift가 임계치를 넘을 때 state rank나 attention window를 늘린다. 평균 FLOPs뿐 아니라 peak memory와 p95를 함께 보고해야 한다.

개입 기반 benchmark

단순 관측을 넘어 BOS 교체, prefix permutation, sink regularization, residual scaling, attention insertion을 randomize해 downstream task 변화를 측정한다. 지표는 성공 작업당 Joule, p95 latency, 근거 회수율, 오류 복구율, sink concentration, state contamination recovery를 포함한다.

ETRI 단계적 실증

  1. 통제실험: 동일 학습 데이터·quantization·하드웨어에서 Mamba-2, Mamba-3, hybrid, Transformer 비교.
  2. 강건성: 상태 오염, 통신 단절, sensor dropout, context reset, adversarial prefix 시험.
  3. 현장실증: 장기 로봇·설비 운용에서 task success와 energy를 함께 측정하고 안전 경계를 별도 인증.
제안연구의 다음 단위는 “모델 한 번의 정답”이 아니라 오랜 세션 동안 서로 다른 증거가 한 attractor에 흡수되지 않으면서, 필요한 근거를 낮은 비용으로 다시 읽는 시스템이어야 한다.
