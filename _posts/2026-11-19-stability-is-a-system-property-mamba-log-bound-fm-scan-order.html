THE CENTRAL QUESTION

길이에 무관한 수학적 상계와 안정성 제약이 실제 장기 세션·2D 비전·불규칙 공간의 신뢰성으로 이어지려면 무엇을 더 증명하고 측정해야 하는가?

이번 후속 글은 새 프리프린트 세 편과 실질 개정 한 편을 기존 LFM·Mamba 지식에 통합한다. A Log-Timescale Perturbation Bound는 선택적 scan의 timescale을 절대 차이가 아닌 로그 비율로 측정해 모든 sequence length에 적용되는 셀 상계를 증명한다. FM-Mamba는 2D Fornasini–Marchesini recurrence에 축별 입력 의존 step과 안정 구간 투영을 결합한다. GaussianMamba와 크게 개정된 SFMambaNet은 불규칙 공간을 1D로 읽을 때 scan order 자체가 inductive bias임을 보강한다.

PART 01
01

Definition

이름이 비슷해도 같은 계보가 아니다

LFM(Liquid Foundation Models)은 Liquid AI의 모델군이다. Mamba는 입력 의존적인 선택적 상태공간 아키텍처 계열이다. Liquid Time-Constant Networks(LTC), Liquid Neural Networks(LNN), LFM, Mamba는 서로 다른 연구·제품 계보다. LFM = LTC = LNN = Mamba라는 동일시는 잘못이다.

사실LFM2 기술보고서가 공개한 구조는 입력 의존 게이트가 있는 단거리 합성곱과 일부 grouped-query attention(GQA)의 결합이다. 이는 LFM2에 한정된 설명이며 다른 LFM 세대에 소급하지 않는다. 이번 새 논문 네 편은 Liquid AI의 LFM 논문이 아니라 선택적 SSM/Mamba의 안정성·2D recurrence·scan ordering을 다룬다.

이번 업데이트의 용어

Log-timescale perturbation

두 run의 step size Δ 차이를 |log Δ − log Δ̃|≤ρ라는 상대적 조건으로 측정한다. 작은 timescale에서 절대 오차가 input weight보다 커지는 문제를 피한다.

FM-Mamba

2D 격자의 두 축과 대각 predecessor를 함께 갱신하는 native 2D selective SSM이다. 두 축의 step을 위치·방향별로 선택하고 안정 구간 밖 값은 투영한다.

Scan order

불규칙 집합을 Mamba가 읽을 sequence로 직렬화하는 규칙이다. 이 순서는 어떤 원소가 가까운 이웃인지 결정하므로 단순 전처리가 아니라 모델 가정이다.

System stability

상태 전이의 수학적 안정성, discretization, scan order, 저정밀 오차, kernel 실행, reset·복구를 함께 만족하는 운영 속성이다.

Core Concepts

Selective SSM: 선택성은 추론 중 학습이 아니다

ht = Ātht−1 + B̄txt,    yt = Ctht

Ā_t는 이전 상태의 유지·감쇠, B̄_t는 현재 입력의 기록, C_t는 상태의 읽기를 조절한다. 선택성은 입력마다 기억·망각·읽기 강도를 바꾸는 것이며 추론 중 모델 가중치를 업데이트한다는 뜻이 아니다. 순환 상태 크기가 문맥 길이에 독립이라는 사실도 무한 정보를 완전 보존한다는 뜻이 아니다.

길이에 무관한 상계가 나오는 이유

정확한 zero-order hold(ZOH)에서 scalar cell은 h_t=Ā_t h_(t−1)+(1−Ā_t)c_t로 쓸 수 있다. 즉 이전 상태와 입력 의존 equilibrium c_t의 볼록 결합이다. timescale을 로그 비율로 제한하면 transition 변화가 같은 step의 input weight 1−Ā_t에 비례한다. 오차를 밀어 넣는 항과 수축 항이 같은 작은 계수를 공유하므로 step별 오차가 길이에 따라 단순 누적되지 않는다.

E = η + 2M(eρ−1),   |ht−h̃t| ≤ Pt|h−1−h̃−1| + (1−Pt)E

여기서 η는 equilibrium 변화 상계, M은 perturbed equilibrium/state 범위, ρ는 log-timescale 변화 상계, P_t는 transition 곱이다. 논문은 common start에서 이 상계가 작은 ρ에 대해 가능한 최선의 범용 상계와 약 2배 이내라고 구성으로 보인다. 다만 실제 block certificate는 gradient attack이 찾은 변화보다 10만 배 이상 커 매우 느슨하다.

Introduction

이전 연구 흐름은 선택적 scan의 효율, hybrid attention의 기억 회수, 음의 고유값과 structured transition의 표현력, Mamba-3의 이산화·complex state·MIMO, GPU 공동설계를 차례로 확장했다. 이번 업데이트는 그 위에 두 종류의 “안정성”을 얹는다. 하나는 입력이 조금 바뀌었을 때 상태가 얼마나 달라지는지에 대한 상계이고, 다른 하나는 2D 격자의 discrete recurrence가 국소 증폭을 일으키지 않도록 step을 제한하는 설계다.

동시에 GaussianMamba와 SFMambaNet v2는 상태 전이가 같아도 무엇을 다음 토큰으로 놓는지에 따라 모델이 보는 이웃이 달라진다는 점을 보여준다. 3D Gaussian primitive는 scale·orientation을 가진 불규칙 집합이고, 이미지 대응점은 대부분 outlier인 unordered set이다. 이 데이터를 임의로 1D sequence로 읽히면 Mamba의 long-range efficiency가 올바른 관계를 보존한다는 보장은 없다.

해석연구의 초점은 “효율적인 연산자”에서 “안정적인 표현·순서·이산화·실행의 공동설계”로 이동하고 있다. 이는 네 논문을 통합한 해석이며 저자들이 공동으로 입증한 단일 정리가 아니다.
경계Log-timescale 정리는 scalar cell 가정에서 출발하고, FM-Mamba는 COCO image-level multi-label classification, GaussianMamba는 두 3D occupancy benchmark, SFMambaNet은 two-view correspondence에 한정된다. 어느 모델도 모든 조건에서 우월하다고 주장할 근거는 없다.

Motivation and Background

Mamba 원 논문은 2023년 최초 공개된 배경 연구다. Mamba-2/SSD와 native 2D SSM 다수는 2024년 공개된 배경 연구이며, 2025년 Samba는 SSM과 sliding-window attention의 hybrid를 정식 발표했다. 음의 고유값 연구는 2024년 최초 공개 후 ICLR 2025에 발표되어 state tracking 표현력의 전이 구조 의존성을 강조했다. 2025년 LFM2 기술보고서는 hardware-in-the-loop architecture search, Top-K distillation, curriculum·post-training을 구조와 함께 제시했다.

2026년 Mamba-3는 exponential–trapezoidal discretization, complex-valued state, MIMO를 도입했다. 이후 연구는 GPU kernel fragmentation, persistent multi-state, causal ablation, low-precision recurrence로 확장됐다. 이번 네 근거는 여기에 relative timescale certificate, 2D stability-aware projection, geometry/semantics/frequency-aware order를 추가한다.

Challenges

1 · 정확 회수와 압축의 충돌

유한 상태는 이력을 요약한다. 추세와 동역학에는 유리하지만 identifier·근거 문장·과거 사건의 exact recall에는 병목이 된다.

2 · 기억과 상태 추적의 차이

과거 값을 재현하는 기억과 현재 세계 상태를 갱신하는 tracking은 전이 구조, reset, metric이 다르다.

3 · Certificate gap

모든 입력에 대한 보증은 공격이 찾은 실제 변화보다 5 orders 이상 클 수 있다. 유효한 정리가 곧 실용적 certificate는 아니다.

4 · 양자화 누적 오차

BF16·FP8·INT8의 작은 편향이 recurrent update를 따라 누적될 수 있다. 이번 log-timescale 정리는 이를 직접 분석하지 않는다.

5 · 순서와 내용의 얽힘

scan order가 이웃을 바꾸면 내용 표현력과 permutation sensitivity를 분리하기 어렵다. 크기·경로·capacity 통제가 필요하다.

6 · Kernel과 이론 비용의 격차

FM-Mamba의 O(HWn) 계산도 실제 GPU에서는 wavefront dispatch, buffer, graph capture에 따라 p95·memory가 달라진다.

훈련 길이 밖 일반화, 데이터·증류·아키텍처 효과 분리, CPU/GPU/NPU kernel 차이도 남는다. 특히 FM-Mamba의 per-shape dispatch는 throughput을 크게 높이지만 CUDA Graph residency 때문에 peak inference memory가 약 114 MiB에서 468 MiB로 증가했다. 한 지표 개선을 전체 효율로 환원할 수 없다.

Approaches (Methods)

8.1 Log-timescale bound: 절대 변화 대신 비율을 추적

저자들은 exact ZOH scalar cell을 이전 상태와 equilibrium의 convex update로 바꾸고, 두 run의 timescale ratio를 e^ρ 이내로 제한한다. transition 차이가 input weight의 고정 비율보다 크지 않다는 ratio lemma에서 출발해 길이에 무관한 cell theorem을 얻는다. 이어 Mamba 공개 코드의 exponential-Euler input term으로 확장하되 timescale upper bound를 추가한다.

저자 주장작은 perturbation에서 범용 상계는 구성적 lower bound의 약 2배 이내다. 두 개의 작은 two-block 모델을 하루치 limit-order-book 데이터로 학습했을 때, bounded timescale 조건에서 기존 additive 분석이 더 타이트한 구간은 최대 첫 8 step이었다. Mamba softplus timescale의 certified floor는 약 10−21까지 작아 기존 bound가 모든 시험 길이에서 더 느슨했다.
제한상계는 모든 block input에 대해 성립하지만 gradient attack이 찾은 변화보다 5 orders of magnitude 이상 크다. 일부 보조 정리는 Isabelle/HOL로 확인됐지만 main ratio lemma·cell theorem·lower bound와 Python interval propagation 전체가 기계검증된 것은 아니다.

8.2 FM-Mamba: 두 축의 selective step과 안정 구간 투영

FM-Mamba는 현재 위치 (i,j)의 상태를 위, 왼쪽, 대각 predecessor와 현재 입력으로 갱신한다. 두 입력 의존 step Δ₁(i,j), Δ₂(i,j)가 각 축 전파를 조절한다. normalized ratio r_k=a₀,k/(a₁,k a₂,k)에서 closed-form stable interval을 만들고, 밖으로 나간 step을 10% margin 안쪽으로 투영한 뒤 post-training per-position으로 재검증한다.

h(i,j)=Ã₁h(i−1,j)+Ã₂h(i,j−1)+Ã₀h(i−1,j−1)+B̃x(i,j)

dual-diagonal wavefront는 두 anti-diagonal buffer만 유지해 저자 분석상 compute O(HWn), depth O(H+W), parallelism min(H,W), state residency O(min(H,W))를 갖는다. 이는 1D flattening의 2~4개 scan과 2D↔1D 변환을 피하지만, 전체 모델의 activation·attention·framework memory까지 길이 독립이라는 뜻은 아니다.

8.3 GaussianMamba: 기하와 의미를 서로 다른 순서로 읽기

첫 branch(CGSS)는 Gaussian scale·orientation으로 anisotropic support를 계산하고 locality-preserving traversal을 local swap으로 다듬는다. 둘째 branch(DRSS)는 공간 group을 feature·semantic affinity로 재배치하고 경계의 의미 차이를 support-weighted correction으로 반영한다. 두 Mamba 출력은 서로 다른 scan에서 생긴 local contrast 차이를 이용해 fusion한다.

저자 주장nuScenes-SurroundOcc에서 GaussianFormer에 결합했을 때 IoU/mIoU가 29.83/19.10에서 32.41/20.55로, GaussianFormer-2에서는 30.56/20.02에서 32.98/21.12로 향상됐다. 그러나 144K Gaussian에서 추가 scan latency는 111.42 ms였고, backbone·Gaussian count에 따라 gain이 달랐다.

8.4 SFMambaNet v2: 순서를 주파수 가설로 검증

2026-11-17의 v2는 제목·저자·분석·실험·부록을 크게 확장했다. 대응점을 cluster-by-cluster로 읽어 inlier는 sequence에서 천천히, outlier는 빠르게 변한다는 가설을 세우고 forward/backward Mamba 사이에 learnable frequency gate를 둔다. parameter-free low-pass filter가 같은 규모의 point-wise layer보다 강했고, 학습된 gate는 스스로 low-pass가 되었으며 shuffle 민감도가 줄었다는 저자 보고는 extra capacity만으로 gain을 설명하기 어렵게 만든다.

해석GaussianMamba와 SFMambaNet의 공통점은 “Mamba block을 어디에 붙였는가”보다 어떤 인접성을 sequence로 번역했는가가 중요하다는 것이다. 이 해석은 unordered point·graph·sensor set으로 확장 가능한 연구 가설이지 아직 보편 정리가 아니다.

PART 10
10

Open Problems

유한 상태의 과제별 기억 한계

길이와 무관한 perturbation bound는 상태의 정보 용량을 늘리지 않는다. “작은 입력 변화에 상태가 크게 흔들리지 않는다”와 “수십만 step 전의 식별자를 정확히 회수한다”는 서로 다른 명제다. state dimension, precision, task entropy에 따른 기억 한계가 필요하다.

망각 탐지와 session 복구

모델이 틀린 상태를 계속 carry할 때 언제 reset할지, 부분 상태만 고칠지, 원 기록을 replay할지 기준이 없다. 장기 session drift와 reset 비용을 accuracy 밖의 독립 지표로 만들어야 한다.

공정 비교와 실세계 안전성

FM-Mamba의 throughput, GaussianMamba의 IoU, SFMambaNet의 correspondence 지표는 서로 다른 데이터·규모·hardware에서 나왔다. 동일 학습 데이터, parameter·FLOP·tuning budget, precision, batch, kernel maturity를 맞춘 비교 없이는 순위를 만들 수 없다.

한국어 전문업무

한국어 약어, 기관별 장문 문서, 날짜가 바뀐 규정, 다자 지시와 센서 event를 동시에 유지하는 평가가 부족하다. sequence order를 문서 구조·시간·entity 관계로 바꿨을 때 회수율·hallucination·energy가 어떻게 달라지는지 검증해야 한다.

안정성 상계, 실제 robustness, exact recall, 물리적 safety는 서로 대체할 수 없는 네 개의 검증 축이다.
