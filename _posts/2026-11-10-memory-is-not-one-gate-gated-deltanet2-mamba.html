THE CENTRAL QUESTION

고정 크기 메모리의 병목은 “얼마나 저장하는가”인가, 아니면 “무엇을 지우고 무엇을 쓸지 분리하지 못하는가”인가?

Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention는 2026년 5월 21일 v1이 공개됐고, NeurIPS 2026 채택 정보를 포함한 v2가 2026년 11월 6일 개정됐다. 11월 9일 arXiv 교체 제출 목록에 반영된 이 버전은 Mamba-2·Mamba-3와 직접 비교한 대규모 근거, state-tracking 부록, 하드웨어 비용을 함께 제시한다.

이번 갱신의 의미는 Mamba가 틀렸다는 결론이 아니라, 고정 상태 모델의 경쟁축이 상태 크기에서 메모리 편집 규칙으로 이동하고 있음을 보여주는 비교 근거라는 데 있다.

PART 01 · DEFINITION
01

정의: LFM, Mamba, linear attention은 같은 이름이 아니다

LFM은 Liquid AI의 모델군이며, Mamba는 입력에 따라 상태 전이와 쓰기를 조절하는 selective state-space architecture다. Gated DeltaNet-2는 상태공간 모델이 아니라 delta-rule 기반 recurrent linear attention 계열이다. 세 계열은 긴 문맥을 낮은 비용으로 처리한다는 목표를 공유하지만, 상태 표현과 갱신 법칙이 다르다.

LFM=LTC=LNN=Mamba라는 동일시는 잘못이며, LFM2의 gated short convolution+GQA 구조를 다른 LFM 세대에 소급해서도 안 된다. 이번 조사 기간에 Liquid AI의 최신 모델 발표는 2026년 10월 27일 LFM3였고, 11월 10일 기준 새 LFM 논문·모델 발표는 확인되지 않았다.

사실Gated DeltaNet-2의 비교 대상에 Mamba-2, Mamba-3 SISO/MIMO가 포함되므로 Mamba 연구의 외부 검증 근거로는 중요하다. 그러나 그 자체를 “Mamba-4”나 Mamba의 변형으로 부르는 것은 부정확하다.
PART 02 · PROBLEM DEFINITION
02

문제 정의: 기억 용량보다 기억 간섭을 제어한다

공통 목표는 긴 이력, 낮은 추론 비용, 높은 정확도를 동시에 만족시키는 것이다. 이를 품질 최대화와 p95 지연·피크 메모리·에너지 제약의 다목적 문제로 쓰면 다음과 같다.

maximize Quality(θ) subject to p95 ≤ L, peak-memory ≤ M, joule/success ≤ E, retrieval ≥ R, state-drift ≤ D

표준 full attention의 prefill 연산은 길이에 대해 이차이고, KV cache는 선형이며, decode 한 토큰의 attention은 이력 길이에 선형이다. 고정 상태 recurrent model은 총 연산을 선형으로 만들고 순환 상태 크기를 길이와 독립적으로 유지할 수 있지만, 유한 상태 안에서 여러 key–value 연상이 겹치며 발생하는 interference를 피하지 못한다.

Gated DeltaNet-2가 겨냥하는 병목은 “상태가 작다”보다 더 구체적이다. 기존 delta-rule의 scalar gate βt 하나가 오래된 연상을 지우는 강도와 새 값을 기록하는 강도를 동시에 결정한다. 하지만 erase는 key 축에서, write는 value 축에서 작동하므로 두 결정이 항상 같아야 할 이유는 없다.

PART 03 · CORE CONCEPTS
03

핵심 개념: 선택성, delta correction, 두 개의 채널 gate

Selective SSM과 추론 중 학습의 차이

Mamba 계열의 기본 selective recurrence는 다음처럼 요약할 수 있다.

ht = Ātht−1 + B̄txt,   yt = Ctht

선택성은 입력별로 기억·망각·읽기를 조절한다는 뜻이며, 추론 중 모델 가중치를 경사하강으로 다시 학습한다는 뜻이 아니다. 길이에 독립적인 순환 상태도 무한한 정보를 손실 없이 보존한다는 뜻이 아니다.

Linear attention의 행렬 상태

St = St−1 + ktvt⊤,   ot = St⊤qt

단순 누적은 오래된 연상을 직접 제거하지 않는다. DeltaNet은 현재 key에서 읽은 값을 먼저 빼고 목표 value를 쓰는 correction을 추가한다. Gated DeltaNet과 KDA는 decay를 더하지만 active edit의 erase와 write를 하나의 βt에 묶어 둔다.

Gated Delta Rule-2

St = [I − kt(bt ⊙ kt)⊤]DtSt−1 + kt(wt ⊙ vt)⊤

bt는 key-side channel erase gate, wt는 value-side channel write gate다. 두 벡터를 같은 scalar βt로 묶으면 KDA가 되고, decay까지 scalar로 묶으면 Gated DeltaNet이 된다. 새 규칙은 기존 모델을 배제하지 않고 tied subspace로 포함한다.

PART 04 · INTRODUCTION
04

도입: 효율적 연산자 경쟁에서 메모리 편집 경쟁으로

Mamba 연구의 초기 질문은 full attention 없이 긴 시퀀스를 얼마나 빠르게 처리할 수 있는가였다. Mamba-2는 SSD 관점과 head 구조를, Mamba-3는 exponential-trapezoidal discretization·복소 상태·MIMO를 도입해 표현력과 하드웨어 효율을 확장했다. Samba 같은 hybrid는 SSM과 sliding-window attention을 결합해 전역 압축과 국소 정밀 상호작용을 나눴다.

Gated DeltaNet-2 v2는 이 흐름에 다른 질문을 던진다. 고정 상태를 채택했다면, 그 상태 안에서 오래된 연상을 얼마나 세밀하게 수정할 수 있는가? 연구의 중심이 “어떤 연산자를 쓰는가”에서 “압축 메모리를 어떤 규칙으로 편집하는가”로 이동하고 있다는 해석이다.

해석Mamba-3의 MIMO는 한 시점에 여러 독립 값을 쓰는 방향이고, Gated DeltaNet-2는 이미 저장된 연상과 새 값을 서로 다른 채널 정책으로 수정하는 방향이다. 둘은 경쟁하면서도 결합 가능한 설계축이다.
PART 05 · MOTIVATION & BACKGROUND
05

배경: 기억·회수·상태 추적은 서로 다른 능력이다

Associative retrieval

key가 주어졌을 때 연결된 value를 회수한다. 연상 간 간섭과 overwrite 정책이 핵심이다.

State tracking

입력 순서에 따라 내부 상태를 정확히 갱신한다. 음의 고유값·회전·반사형 전이가 중요할 수 있다.

Local aggregation

근처 증거를 정렬·비교·결합한다. 고정 상태만으로 불리하면 SWA가 보완한다.

Long-context memory

길이가 늘어도 관련 정보를 보존한다. 용량뿐 아니라 relevance signal 도착 시점과 편집 정책이 좌우한다.

이 구분은 결과 해석에 필수다. Gated DeltaNet-2는 retrieval에서 강하지만 NQ와 DROP처럼 국소 증거 집계가 필요한 과제에서는 pure recurrent보다 SWA hybrid가 유리하다. 반대로 permutation composition은 음의 전이 범위를 열어야 성능이 올라가며, 가장 어려운 S5의 절대 정확도는 여전히 매우 낮다.

PART 06 · CHALLENGES
06

난제: 표현력, 병렬화, 저정밀 안정성을 동시에 지킨다

  1. 압축–회수 충돌: 상태 크기가 고정되면 서로 다른 연상이 같은 좌표를 공유한다.
  2. erase/write 식별: 어떤 채널을 지울지와 어떤 채널을 쓸지 따로 학습해도 causal role을 분리하기 어렵다.
  3. 병렬 학습: 순환 규칙을 chunkwise WY 형태로 바꾸면서 정확한 backward를 유지해야 한다.
  4. 저정밀 누적: decay와 상태 갱신 오차가 긴 시퀀스에서 누적될 수 있다. 논문 구현은 log-decay와 recurrent state의 일부를 fp32로 처리한다.
  5. 훈련 길이 밖 일반화: 4K에서 훈련한 모델의 8K retrieval과 128→512 state tracking을 넘어 더 긴 세션에서 안정성을 확인해야 한다.
  6. 하드웨어 비용: 두 벡터 gate는 표현력을 늘리지만 projection·elementwise 연산·backward accumulator를 추가한다.
  7. 공정 비교: 데이터, 토큰 수, state size, attention 배치, 정밀도, 커널 성숙도를 동시에 맞춰야 한다.
검증 경계논문의 1.3B 주요 표는 single-run 값이다. 일부 state-tracking 실험만 3 seeds 평균±표준편차를 제공한다. 따라서 작은 점수 차이를 보편적 우위로 읽으면 안 된다.

31.6B hybrid latent-MoE scaling

저자들은 31.6B total/3.2B active parameters, 300B tokens의 Nemotron-3 Nano-style hybrid latent-MoE에서도 global attention 위치·state size·active parameters·training recipe를 고정하고 recurrent mixer만 바꿨다. 전체 평균은 Mamba-2 60.14, KDA 61.25, Gated DeltaNet-2 62.67로 보고됐다. 이는 global attention이 있어도 recurrent update가 무의미해지지 않는다는 저자 주장을 뒷받침한다.

State tracking과 hardware

Permutation composition은 길이 128 훈련→512 평가, 3 seeds다. 확장 erase 범위 [0,2]를 쓴 Gated DeltaNet-2는 S3/S4/A5/S5에서 74.2/28.6/9.7/2.8%를 보고했지만, 가장 어려운 S5의 2.8%는 절대 성능이 여전히 매우 낮다는 한계를 드러낸다.

single H100 hybrid training throughput은 길이가 증가할 때 38.0→36.1 Ktokens/s로 완만하게 감소했다. Blackwell SM100, 8K prefix, batch 1–16의 kernel-level modeled decode latency는 KDA보다 4.3–6.5% 높았다. 이는 실제 end-to-end 사용자 지연·전력 측정이 아니다.

PART 09 · KEY APPLICATIONS
09

활용: 간섭이 큰 스트리밍 메모리에 적합한 가설

  • 온디바이스 assistant: 고정 상태로 긴 대화 이력을 압축하면서 preference·task state를 선택적으로 갱신.
  • 로컬 RAG: 여러 key–value evidence가 겹칠 때 오래된 연상을 지우고 새 근거를 채널별로 기록.
  • 스트리밍 센서 분석: 장비 상태 변화와 이벤트를 연속적으로 반영하되 메모리를 길이에 따라 늘리지 않음.
  • agent memory: 도구 실행 결과, 실패 원인, 복구 정책을 서로 다른 write admission으로 관리.
연구 제안ETRI/Physical AI에서는 센서 상태 추적, 로봇의 고수준 계획, 통신 단절 시 edge operating intelligence에 적용할 수 있다. 다만 이는 논문이 직접 검증한 결과가 아니며, 저수준 제어 안전성·실시간 worst-case latency·상태 오염 회복은 별도 실증이 필요하다.
PART 10 · OPEN PROBLEMS
10

미해결 문제: 더 잘 쓰는 메모리도 언젠가는 잊는다

  • 과제별 finite-state limit: 필요한 연상 수가 state rank를 넘어갈 때 실패 지점을 예측할 이론이 부족하다.
  • forgetting detector: model이 어떤 정보를 덮어썼는지 스스로 감지하고 외부 메모리를 호출하는 방법이 없다.
  • long-session drift/reset: 수십만·수백만 token 세션의 state 오염, reset, checkpoint 전략이 검증되지 않았다.
  • quantization: fp32 decay/state 보조 없이 INT8/INT4 NPU에서 안정적인지 알 수 없다.
  • fair kernels: Mamba-3, KDA, Gated DeltaNet-2의 kernel maturity와 compiler support가 실제 p95를 왜곡할 수 있다.
  • data–architecture separation: 100B/300B 규모 결과에서 데이터 순서와 recipe 효과를 완전히 분리하기 어렵다.
  • Korean professional work: 한국어 장기 문서·정책 근거 회수·도구 사용에서 동일한 이점이 확인되지 않았다.
PART 11 · FUTURE DIRECTIONS
11

향후 방향: 압축 상태·attention·외부 증거를 계층화한다

제안 1 — hierarchical memory. 압축 recurrent state는 지속적 요약을, 필요 구간 attention은 정밀 비교를, 외부 evidence memory는 출처 보존과 재검증을 담당하게 한다. 내부 상태 하나에 모든 기억 책임을 몰지 않는다.

제안 2 — adaptive budget. erase/write conflict, retrieval uncertainty, state norm drift가 임계값을 넘을 때 MIMO rank, attention window, 외부 검색 예산을 동적으로 늘린다.

제안 3 — joint architecture/hardware search. bt/wt 자유도, state size, attention 비중, precision을 CPU/GPU/NPU kernel과 함께 탐색한다. 이론적 O(1) state와 실제 p95 latency·energy는 별도 목적함수다.

제안 4 — ETRI benchmark. 동일 학습데이터·token budget·quantization·hardware에서 Mamba-2/3, Gated DeltaNet-2, hybrid를 비교하고 성공 작업당 Joule, p95 latency, 근거 회수율, 오류복구율을 함께 측정한다. 상태 오염, 센서 누락, 통신 단절, 장기 로봇/설비 세션을 단계적으로 검증한다.

종합 해석2025–2026 연구 흐름은 효율적인 연산자 발명에서 기억 회수·상태 추적·하드웨어 및 학습 공동 설계로 이동한다. Gated DeltaNet-2 v2는 그 전환을 보여주는 강한 비교 근거지만, 어느 모델이 모든 조건에서 우월하다는 증거는 아니다.
