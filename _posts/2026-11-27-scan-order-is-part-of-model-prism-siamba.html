PART 01
01

Definition

사실LFM(Liquid Foundation Models)은 Liquid AI가 개발하는 모델군의 이름이고, Mamba는 입력 의존적 선택성을 갖는 상태공간 아키텍처 계열이다. LTC(Liquid Time-Constant network)와 LNN(Liquid Neural Network)은 또 다른 연속시간·동역학 계보이므로 LFM=LTC=LNN=Mamba라는 동일시는 틀리다.

LFM2는 Liquid AI의 해당 세대 기술보고서가 밝힌 범위에서 입력 의존 게이트를 둔 단거리 합성곱과 일부 GQA(Grouped-Query Attention)를 조합한다. 이 설명을 다른 LFM 세대에 소급해서는 안 된다. 반대로 Mamba와 그 시각 변형은 토큰·패치 순서를 따라 고정 크기 상태를 갱신하는 선택적 SSM을 핵심 연산으로 삼는다.

이번 범위2026년 11월 27일 KST까지 다시 확인한 Liquid AI의 공식 연구 목록에서는 전날 글 이후 새 LFM 논문을 찾지 못했다. 오늘의 증분은 Mamba 계열 두 연구다. PRISM은 방법론적 직접 근거, SIAMBA는 응용 시스템 검증 근거로 분류한다.

Problem Definition

공통 문제는 긴 이력과 낮은 비용, 높은 정확도를 동시에 만족시키는 것이다. 이미지 압축에서는 이전에 복호화된 잠재 토큰을 정확히 이용하면서 비트율과 생성 왜곡을 줄여야 한다. 홍수 변화 탐지에서는 센서별 잡음과 관측 조건이 다른 두 시점의 신호를 통합하면서 작은 침수 영역을 놓치지 않아야 한다.

maximize  Qtask, Qperceptual, Revidence
subject to  bitrate ≤ B,  p95 latency ≤ L,  peak memory ≤ M,  energy/task ≤ E,  safety error ≤ S

해석이는 한 개 점수의 최대화가 아니라 제약된 다목적 설계다. PRISM은 비트율·지각 품질·왜곡의 파레토 전선을, SIAMBA는 IoU·전체 정확도와 센서 강건성을 다룬다. 실제 배포에서는 여기에 p95 지연, 피크 메모리, 에너지, 오류 복구를 더해야 한다. “더 선형인 연산자”는 이 목적함수의 한 항목이지 전체 해답이 아니다.

03

Core Concepts

선택적 상태공간 모델: 기억·망각·읽기의 입력별 조절

ht = Āt ht−1 + B̄t xt,    yt = Ct ht

사실선택성은 입력 xt에 따라 상태 전이·쓰기·읽기 계수가 달라져 무엇을 유지하고 버릴지를 조절한다는 뜻이다. 이는 추론 중 모델 가중치를 새로 학습한다는 뜻이 아니다. 순환 상태의 크기가 이력 길이에 독립이라는 말도 무한한 정보를 손실 없이 저장한다는 뜻이 아니다. 유한 상태는 과제에 필요한 통계를 압축하며, 압축 과정에서 정확 회수와 상태 추적이 충돌할 수 있다.

스캔 순서는 계산 그래프의 인과관계다

2차원 이미지를 SSM으로 처리하려면 픽셀·패치를 1차원 순서로 펼쳐야 한다. 이때 순서 π는 단순한 메모리 배치가 아니다. 상태 hj가 어떤 토큰을 먼저 본 뒤 다음 토큰을 예측하는지 정한다. PRISM의 핵심은 알려진 토큰 집합 K를 먼저, 다음 복호화 대상 U를 나중에 놓는 것이다.

πt,g = [ raster(Kt,g), raster(Ut,g) ]
hj = exp(ΔjA)hj−1 + ΔjBjuj,   oj = Cjhj + Duj

Attention과 SSM의 비용을 과장하지 않기

표준 full attention의 prefill 연산은 문맥 길이에 대해 이차이며, KV cache는 선형으로 증가하고, decode 시 한 토큰의 attention은 이력 길이에 선형이다. 고정 상태 크기의 순수 SSM은 전체 순차 연산이 선형이고 순환 상태는 길이에 독립적이다. 그러나 LFM2처럼 full attention 또는 GQA를 섞은 전체 모델을 O(1) 메모리·완전 선형이라고 부를 수는 없다. GQA는 KV 크기의 계수를 줄이지만 길이에 대한 선형 의존 자체를 없애지 않는다.

PART 04
04

Introduction

최근 Mamba 연구의 질문은 “attention을 없앨 수 있는가”에서 “고정 상태에 무엇을 담아야 실제 작업이 성공하는가”로 이동하고 있다. 앞선 연구들이 음의 고유값, 복소수 상태, MIMO, hybrid attention, 외부 메모리 등 상태 전이의 표현력과 회수 능력을 넓혔다면, 이번 두 연구는 데이터가 모델에 들어오는 순서와 증거의 형태가 같은 수준으로 중요하다는 현장 근거를 제공한다.

PRISM은 극저비트율 생성 압축에서 엔트로피 모델이 복호화 순서와 어긋나면 이미 알고 있는 문맥을 충분히 활용하지 못한다는 문제를 다룬다. SIAMBA는 변화 탐지에서 단순 feature subtraction 대신 절대차·부호차·상대 로그비를 명시적으로 만들고, 센서별 인코더와 Mamba 문맥화를 결합한다. 하나는 순서 정렬, 다른 하나는 증거 정렬의 사례다.

해석연구의 단위가 연산자에서 시스템으로 커지고 있다. 효율적인 SSM 블록이 있어도 스캔이 과제의 인과순서를 거스르거나, 센서의 의미가 섞이거나, 상태가 탭마다 초기화되면 전체 시스템은 필요한 기억을 잃는다.

05

Motivation and Background

배경 연구와 2025년 이후 흐름

Mamba 원논문은 2023년에 최초 공개된 배경 연구다. 입력 의존 선택성과 하드웨어 친화적 scan을 결합해 긴 시퀀스의 선형시간 처리를 제시했다. VMamba는 2024년 최초 공개된 배경 연구로, 다방향 2D selective scan을 통해 비전 과제로 확장했다. 이들은 이번 기간의 신규 논문이 아니므로 배경으로만 사용한다.

2025년에는 Samba 같은 SSM+sliding-window attention 혼합, 상태 추적의 음의 고유값 조건, SSM의 계산 한계, MemMamba의 계층·토큰 간 메모리 보강이 등장했다. 2026년 Mamba-3는 exponential–trapezoidal 이산화, 복소수 상태, MIMO를 통해 상태 동역학과 표현력을 확장했다. 이 흐름 위에서 PRISM은 scan의 과제 정렬, SIAMBA는 멀티모달 변화 증거의 구조화를 추가한다.

왜 압축과 재난지도인가

극저비트율 압축

0.05 bpp 아래에서는 모든 세부를 보존할 수 없다. 비트스트림에 남은 증거와 생성 prior가 충돌하며, 텍스트·윤곽처럼 작은 구조가 쉽게 환각된다.

홍수 변화 탐지

SAR는 구름에 강하지만 speckle과 산란 특성이 있고, 광학은 의미가 직관적이지만 구름·조도에 취약하다. 서로 다른 오류 구조를 분리해 다뤄야 한다.

동기두 과제는 공통적으로 “긴 문맥”보다 더 구체적인 질문을 던진다. 어떤 증거를 어떤 순서로 압축 상태에 주입해야 하는가? 이 질문은 로봇 센서 융합, 로컬 RAG, 스트리밍 이상 탐지에도 직접 이어진다.

06

Challenges

정확 회수 ↔ 압축

유한 상태가 평균적 문맥을 잘 요약해도 작은 글자·희귀 사건·정확한 좌표를 잃을 수 있다. PRISM의 pseudo-glyph는 이 충돌을 시각적으로 드러낸다.

기억 ↔ 상태 추적

과거 토큰을 복사하는 능력과 현재 세계 상태를 올바르게 갱신하는 능력은 다르다. cross-tap carry는 연속성을 주지만 잘못된 상태도 전파할 수 있다.

표현력 ↔ 인과 식별

SIAMBA는 encoder, gating, discrepancy, skip attention, decoder를 함께 바꾼다. 완성 시스템의 향상만으로 Mamba 블록의 순효과를 분리할 수 없다.

연산량 ↔ 실제 지연

GPU 커널, 메모리 이동, 병렬 batch, 해상도, 정밀도에 따라 이론 복잡도와 CPU/GPU/NPU p95 지연 사이의 격차가 커진다.

저정밀 ↔ 장기 안정성

양자화 오차는 반복 상태 갱신에서 누적될 수 있다. 짧은 정적 벤치마크의 정확도가 장기 세션 안정성을 보증하지 않는다.

합성 과제 ↔ 실세계 성공

state-tracking 점수와 실제 agent·재난 대응의 성공률, 에너지, 오류 복구율 사이의 연결은 아직 충분히 검증되지 않았다.

Research Questions

  1. 동일 메모리 예산에서 무엇을 기억해야 하는가? 평균 문맥, 희귀 토큰, 위치, 불확실성 중 과제 성공에 필요한 충분통계는 무엇인가?

  3. 상태를 언제 이어 주고 언제 초기화해야 하는가? cross-tap carry의 이득과 오염 전파를 confidence gate로 분리할 수 있는가?
  4. 최소 attention 비중과 배치는 무엇인가? 필요한 구간에만 정확 회수를 제공하는 attention이 어느 층·어느 이벤트에 있어야 하는가?

  6. 센서 증거의 불일치를 어떻게 보존할 것인가? 강제 융합보다 modality-specific state와 명시적 disagreement가 더 안전한가?
  7. 합성 state-tracking이 실제 성공률을 예측하는가? 상관관계를 agent 작업, 로봇 계획, 장기 설비 모니터링에서 검정할 수 있는가?
  8. 실제 단말의 성공 작업당 에너지는 얼마인가? 평균 tok/s 대신 Joule/success, p95 latency, 복구 후 성공률을 보고할 수 있는가?

08

Approaches (Methods)

PRISM: 복호화 순서에 맞춘 VSS 엔트로피 모델

방법PRISM은 4개 탭으로 잠재 표현을 순차 부호화한다. 조건부 확률은 p(ŷ|ẑ)=∏ₜ p(ŷₜ|ŷ<ₜ,ẑ)로 분해된다. 각 탭·채널 그룹에서 이미 복호화된 K를 먼저 훑고 다음 대상 U를 뒤에 둔다. 이전 탭 출력은 4×4로 pooling한 뒤 방향별 16개 prefix token으로 투영해 다음 scan 앞에 붙인다. 따라서 매 탭을 h₀=0에서 시작하지 않는다.

단일 1.01B 파라미터 모델(학습 가능 221M)은 연속 비트율 제어 λ와 decoder-side realism 제어 β를 제공한다. 같은 bitstream을 다시 인코딩하지 않고 β를 바꿔 왜곡–지각 품질을 조절한다. one-step SD-Turbo diffusion decoder, LoRA, frozen VAE decoder를 사용한다.

저자 보고DF2K·CLIC2020·LSDIR 14,119장으로 2×NVIDIA A40에서 3단계 학습했다. 저자들은 0.003–0.06 bpp의 범위를 한 모델로 다루며, fixed-rate AEIC-SE 대비 동일 FID에서 DIV2K 23.5%, CLIC2020 19.9%의 bitrate 절감을 보고한다. 초록의 평균 요약은 약 22%다. 동일 LPIPS 절감은 데이터셋별 6.1–10.6%, 동일 DISTS는 13.4–24.5%다.

검증 해석DOA scan과 state carry를 모두 제거한 설정 대비 둘을 결합한 설정은 동일 PSNR에서 5–6%, 동일 LPIPS에서 11–15%의 bitrate 절감을 보였다고 보고된다. raster scan으로 바꾸면 탭 1–3의 bit cost가 Kodak 1.5%, DIV2K 3.4% 늘었다. 이전 탭 summary를 제거하면 각각 1.1%, 0.4% 늘었다. 이는 스캔 순서와 상태 연속성이 측정 가능한 아키텍처 변수라는 직접 근거다.

한계생성 압축은 현실감과 원본 충실도 사이를 교환한다. 저자들은 낮은 bitrate에서 원치 않는 세부가 생성되고, 0.0064 및 0.0031 bpp에서 작은 글자가 읽을 수 없는 pseudo-glyph가 되는 사례를 제시한다. PSNR은 distortion-oriented codec보다 낮다. 1.01B 모델의 실제 온디바이스 메모리·에너지는 보고되지 않았다.

SIAMBA: 센서별 인코더, 명시적 변화량, Mamba 문맥

방법SIAMBA는 Sentinel-1 SAR와 Sentinel-2 multispectral의 전·후 영상을 센서별 pseudo-Siamese encoder로 처리한다. 각 수준에서 dual-pooling squeeze-and-excitation과 표준 Mamba layer를 사용하고, 다음 세 변화량을 만든다.

Dabs=|F₂−F₁|,   Dsgn=F₂−F₁,   Drel=(1/κ)log(F₁/F₂),   κ=6

gate는 G=σ(φ([F₂;F₁;max(F₂,F₁)]))로 구성되며, 세 discrepancy branch를 조절한다. 이후 3×3·5×5·3×3 convolution, residual refinement, attention-refined skip connection, progressive decoder를 거쳐 변화 지도를 만든다. 손실은 weighted BCE와 Dice의 결합이다.

저자 보고OMBRIA의 23개 홍수 사건, 3,376개 이미지에서 256×256 patch, batch 16, 50 epoch, AdamW, RTX 3090 조건으로 학습했다. test set에서 IoU 81.98%, OA 93.57%를 보고하며, 비교군 중 최고 대비 각각 0.76·0.71 percentage point 높다. multimodal은 S2-only보다 IoU 8.91p·OA 4.31p, S1-only보다 15.23p·8.37p 높다.
한계단일 benchmark와 고정 seed이며 confidence interval이 없다. latency·memory·energy·throughput도 보고되지 않았다. encoder, gating, discrepancy, skip attention, decoder가 함께 달라져 향상을 Mamba 하나의 효과로 귀속할 수 없다. OA는 클래스 불균형의 영향을 받으므로 IoU를 우선해서 읽어야 한다.

PART 09
09

Key Applications

온디바이스 시각·음성 보조

연속 stream을 고정 상태로 요약하고, 중요한 frame·segment만 정확 회수하는 혼합 구조가 가능하다. 다만 PRISM 자체가 경량 단말 모델이라는 뜻은 아니다.

로컬 RAG와 증거 압축

대화·문서 이력을 상태로 압축하되 숫자·인용·경고는 외부 evidence memory에 남기는 계층형 설계가 유망하다.

스트리밍 분석

설비 로그, 네트워크, 영상에서 event order와 reset policy를 업무 인과에 맞추면 긴 세션의 비용을 줄일 수 있다.

재난 원격탐사

SAR·광학 센서의 상보성을 이용해 구름·조도·산란의 취약점을 보완할 수 있다. 실제 경보에는 calibration과 사람 검토가 필요하다.

연구 제안ETRI/Physical AI에서는 센서 상태 추적, 로봇의 고수준 계획, 엣지 운영지능에 이 원리를 적용할 수 있다. modality별 상태를 유지하고 통신 단절 때 로컬 상태로 계속 작동하며, 연결 복구 뒤 외부 증거 메모리와 재조정하는 구조다. 단, 모터의 저수준 폐루프 제어와 사람 근접 안전은 별도 실시간·형식 검증 대상으로 분리해야 한다.
PART 10
10

Open Problems

  • 과제별 유한 상태 한계: 작은 문자, 좌표, 희귀 재난 패턴처럼 평균 압축에 불리한 정보의 최소 상태 크기를 모른다.
  • 망각 탐지: 모델이 중요한 증거를 이미 잃었다는 사실을 스스로 측정하고 외부 회수로 전환하는 장치가 부족하다.
  • 장기 drift/reset: state carry가 이득인 구간과 오염을 전파하는 구간을 실시간으로 구분해야 한다.
  • 공정 비교: 동일 데이터, parameter budget, 학습 token, 양자화, hardware, kernel, batch에서 attention·SSM·hybrid를 비교한 공개 실험이 부족하다.
  • 저정밀 장기 안정성: INT8/INT4/NPU에서 반복 갱신 오차와 복소·음의 고유값 구조가 어떻게 상호작용하는지 불명확하다.
  • 데이터·증류·아키텍처 분리: Top-K distillation, curriculum, post-training의 효과가 연산자 자체 효과와 섞인다.
  • 한국어 전문업무: 한국어 법률·의료·재난 문서에서 정확 인용, 전문용어 보존, 장기 회수율을 검증한 결과가 제한적이다.
  • 실세계 안전성: 생성 압축의 환각, 변화 지도의 false negative, 센서 고장·공격·통신 단절을 통합 평가해야 한다.
PART 11
11

Future Directions

1. 압축 상태 + 필요한 구간 attention + 외부 증거 메모리

제안평상시에는 SSM이 저비용 상태를 유지하고, 불확실성·충돌·희귀 event가 감지될 때만 local/full attention을 호출하며, 정확한 텍스트·좌표·출처는 외부 evidence memory에서 가져오는 3계층 구조를 제안한다. 이는 효율과 정확 회수의 충돌을 시스템 수준에서 분리한다.

2. 위험 인지형 적응 스캔과 상태 예산

제안PRISM의 고정된 decode-order alignment를 확장해, 인과 제약 안에서 정보 이득과 위험에 따라 scan 순서를 학습한다. 상태 오염 확률이 높아지면 state dimension·prefix memory·attention window를 일시적으로 늘리고, 안정 구간에서는 다시 줄인다. 목표는 평균 FLOPs가 아니라 필요할 때만 기억 예산을 늘리는 것이다.

3. 검증 단위를 토큰이 아니라 성공 작업으로

benchmark는 throughput만이 아니라 다음을 함께 보고해야 한다.

ENERGY

Joule / successful task

재시도와 복구를 포함한 실제 성공 1건의 에너지.

TAIL

p95 latency

평균이 숨기는 긴 꼬리와 thermal throttling.

EVIDENCE

근거 회수율

숫자·좌표·인용을 원문과 일치하게 회수한 비율.

RECOVERY

오류 복구율

state corruption·sensor dropout 뒤 정상 상태로 복귀한 비율.

4. ETRI 온디바이스 협업지능의 단계적 실증

  1. 통제 비교: 동일 학습 데이터·양자화·hardware·kernel에서 Transformer, pure SSM, hybrid를 비교한다.
  2. 고장 주입: state bit-flip, stale memory, sensor dropout, 통신 단절, 잘못된 external evidence를 주입한다.
  3. 안전 분리: 고수준 계획·운영지능과 저수준 제어를 분리하고 독립 watchdog·fallback을 둔다.
  4. 장기 현장 실증: 로봇·설비의 수주 단위 세션에서 drift, reset, 복구, 사람 개입, Joule/success를 기록한다.
결론Mamba 계열의 다음 경쟁력은 상태 크기가 아니라 상태 거버넌스에 있다. 무엇을 어떤 순서로 기록하고, 불확실할 때 어디서 증거를 다시 읽고, 오염된 상태를 어떻게 폐기하는지가 실제 시스템의 성패를 가른다. PRISM과 SIAMBA는 이 방향을 지지하지만, 어느 아키텍처가 모든 조건에서 우월하다는 결론은 허용하지 않는다.
