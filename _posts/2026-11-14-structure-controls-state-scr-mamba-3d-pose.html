THE CENTRAL QUESTION

효율적인 순환 상태만으로 충분한가, 아니면 무엇을 기억하고 잊을지 도메인 구조가 직접 지시해야 하는가?

2026년 11월 11일 제출되고 11월 13일 공개된 SCR-Mamba는 후자를 택한다. 골격의 뼈 연결과 좌우 대칭을 하나의 문맥으로 만들고, 공간·시간 분기의 선택적 파라미터를 함께 조절한다. 이어서 프레임별 특징은 보존한 채 81·27 프레임 스케일에서 얻은 변화량만 되돌린다. 핵심 진전은 구조를 특징 보강이 아니라 상태 갱신의 제어 변수로 승격한 것이다.

PART 01 · DEFINITION
01

Definition

SCR-Mamba는 단안 비디오의 2D 관절 좌표와 검출 신뢰도 X ∈ R^(T×J×3)를 받아 전체 프레임의 3D 관절 좌표를 예측하는 모델이다. 두 구성요소가 핵심이다. SCSM은 뼈로 연결된 관절과 좌우 대칭 관절을 모아 골격 문맥 K를 만든다. CSIR은 시간축을 3분의 1씩 줄인 거친 스케일에서 생긴 변화량만 원래 프레임 특징에 보탠다.

사실논문은 arXiv v1 프리프린트다. 2026년 11월 14일 기준 정식 학회·저널 발표 기록과 공개 코드가 없으며, 저자들은 코드와 사전학습 모델을 “acceptance 이후” 공개하겠다고 적었다.

Mamba는 입력 의존적 선택성을 갖는 상태공간 아키텍처이고, LFM은 Liquid AI의 모델군이다. LFM2는 gated short convolution과 일부 GQA를 결합하지만, LFM=LTC=LNN=Mamba라는 동일시는 틀리며 LFM2의 구조를 모든 LFM 세대에 소급할 수도 없다.

PART 02 · PROBLEM DEFINITION
02

Problem Definition

단안 3D pose lifting은 하나의 2D 투영이 여러 3D 자세와 양립하는 ill-posed 문제다. 한 프레임의 관절 관계와 여러 프레임의 동작 궤적을 함께 사용해야 하지만, 전체 길이에서 반복적으로 모델링하면 계산비용이 커진다. 반대로 프레임을 강하게 압축하면 손목·발목 같은 세부 위치와 순간 동작을 잃기 쉽다.

maximize Quality(structure, motion, detail)   subject to   p95 latency ≤ L*, peak memory ≤ M*, energy/task ≤ E*

공통 연구 목표는 긴 이력, 낮은 추론비용, 높은 정확도를 동시에 만족하는 다목적 설계다. 평균 MPJPE만 최소화하는 문제가 아니라, 동일 데이터·정밀도·배치·하드웨어에서 tail latency와 에너지를 함께 제한해야 한다. SCR-Mamba는 이 가운데 정확도·MACs·평균 GPU 지연을 측정했지만 p95·peak memory·에너지는 아직 측정하지 않았다.

해석이번 결과가 던지는 더 일반적인 질문은 “Mamba가 attention보다 싼가”가 아니다. 어떤 구조 정보를 상태 제어에 넣고, 어떤 시간척도에 계산을 배분해야 임무 단위 비용이 줄어드는가가 핵심이다.
PART 03 · CORE CONCEPTS
03

Core Concepts

Selective state is controlled memory, not online learning

hₜ = Āₜ hₜ₋₁ + B̄ₜ xₜ    ·    yₜ = Cₜ hₜ

B̄ₜ는 입력을 상태에 얼마나 쓸지, Āₜ는 과거를 어떻게 전파·감쇠할지, Cₜ는 상태를 어떻게 읽을지 결정한다. 선택성은 입력별 기억·망각·읽기 조절이지, 추론 중 모델 가중치를 다시 학습하는 것이 아니다. 순환 상태 크기가 길이에 독립이라는 말도 무한 정보를 완벽히 보존한다는 뜻이 아니다.

Structure-conditioned control

(Δₐ, Bₐ, Cₐ) = Φₐ(Nₐ + K),   a ∈ {spatial, temporal}

같은 프레임의 뼈 이웃과 좌우 대칭 이웃을 모은 K가 두 분기의 step size, state write, state read를 동시에 조절한다. 스캔 내용과 출력 gate는 각 분기 특징에서 생성되므로, 구조 문맥은 “무엇을 처리할지”보다 “그 내용을 상태에 어떻게 넣고 읽을지”를 바꾼다.

Incremental coarse-to-fine transfer

δ = G − D₍c₎Z    ·    Z⁺ = Z + P₍c₎δ

세밀한 특징 Z를 보존하고, 집계 결과 D₍c₎Z와 거친 스케일 모델링 결과 G의 차이 δ만 전달한다. 따라서 전체 coarse feature를 중복해서 더하지 않고, 압축 표현만으로 전체 시퀀스를 재구성하지도 않는다.

PART 04 · INTRODUCTION
04

Introduction

최근 Mamba 연구는 효율적인 연산자를 제안하는 단계에서 벗어나, 무엇을 상태로 남길지, 어느 구조를 상태 전이에 주입할지, 어느 해상도에서 계산할지를 묻는 방향으로 이동하고 있다. D²Mamba는 공간 스캔 경로 자체를 학습 대상으로 만들었고, GMD-Mamba는 3D 방향을 채널 그룹에 분배하고 deep stage에 recurrence를 집중했다. SCR-Mamba는 여기서 한 걸음 더 나아가 도메인 그래프가 selective parameter를 직접 조절하도록 한다.

이 변화는 SSM 연구의 평가 단위도 바꾼다. sequence length 복잡도만으로는 충분하지 않다. 입력 구조, 상태 표현력, 계층적 압축, 커널 구현, 검출기 전처리까지 하나의 시스템으로 봐야 한다. 논문 결과는 이 가설을 pose estimation에서 지지하지만, 로봇·온디바이스 일반화는 별도 실험이 필요하다.

PART 05 · MOTIVATION AND BACKGROUND
05

Motivation and Background

2024년 이전 배경인 원 Mamba는 selective SSM으로 입력 의존적 상태 갱신과 선형 시퀀스 계산을 결합했다. 2025년의 SAMA는 골격 특징·hidden state와 motion timescale을 다뤘고, 2026년 StructMamPose는 identity anchoring과 view transformation으로 구조 추론을 강화했다. SCR-Mamba의 차별점은 하나의 골격 문맥이 공간·시간 분기의 Δ, B, C를 공동 조절한다는 데 있다.

동시에 temporal token pruning 계열은 대표 프레임을 남기고 전체 길이를 복원해 비용을 줄였지만, 제거된 프레임의 세밀한 특징이 후속 모델링에서 빠질 수 있다. 일반적인 skip fusion은 coarse feature 전체를 다시 더해 이미 포함된 세부 성분을 중복시킬 수 있다. CSIR은 multigrid의 coarse correction과 유사하게 “전체 표현”이 아니라 “거친 모델링이 새로 만든 변화”만 보낸다.

해석연구 흐름은 효율적인 연산자에서 구조 조건부 기억, 정확한 회수, 다중 스케일 예산, 하드웨어·학습 공동 설계로 이동하고 있다.
PART 06 · CHALLENGES
06

Challenges

정확 회수 vs 압축

고정 크기 상태와 짧은 coarse sequence는 평균 동작을 담기 쉽지만, 특정 프레임의 작은 관절 변화를 잃을 수 있다.

기억 vs 상태 추적

과거 사실을 다시 찾는 retrieval과 매 프레임 자세를 갱신하는 tracking은 다른 능력이다. 하나의 benchmark로 대체할 수 없다.

저정밀 누적오차

반복 상태 갱신에서 양자화 오차가 길이에 따라 누적될 수 있다. weight와 recurrent state 정밀도를 분리해 측정해야 한다.

훈련 길이 밖 일반화

243-frame 학습·평가가 더 긴 세션, frame drop, 불규칙 sampling에서 유지되는지는 알 수 없다.

효과 분리

구조 조건, 계층 구조, 데이터·증류·post-training의 효과를 동일 update budget 아래 분리해야 한다.

커널과 종단 지연

MACs 감소가 CPU/GPU/NPU latency·memory traffic·energy 감소로 그대로 이어지지 않는다.

검증 경계SCR-Mamba runtime은 RTX 4090 한 장, batch 1/32, 243-frame 입력에서 측정됐다. 2D detection과 flip testing은 제외됐고 p95·peak memory·전력은 보고되지 않았다.
PART 07 · RESEARCH QUESTIONS
07

Research Questions

  1. 동일한 state memory에서 뼈 연결·대칭·접촉·가속도 중 무엇을 반드시 기억해야 하는가?
  2. 정확한 특정 프레임 회수를 위해 필요한 최소 attention 비중과 배치는 얼마인가?
  3. 음의 고유값·복소 상태·MIMO 같은 전이 표현력과 병렬 학습 효율을 어떻게 균형화할 것인가?
  4. bf16·FP8·INT8 recurrent state에서 긴 세션의 drift와 reset 조건은 어떻게 변하는가?
  5. 합성 state-tracking 점수가 실제 human–robot collaboration 성공률과 상관하는가?
  6. 실제 단말에서 성공 작업당 Joule, p95 지연, peak memory는 어느 아키텍처가 유리한가?
  7. 구조 문맥이 잘못되거나 관절이 가려졌을 때 상태 오염을 실행 중 탐지할 수 있는가?

Approaches (Methods)

Architecture and learning contract

Relationship to the broader method landscape

LFM2는 hardware-in-the-loop search, Top-K distillation, curriculum·post-training으로 실제 장치 제약과 학습을 공동 설계했다. Mamba-3는 exponential-trapezoidal discretization, complex states, MIMO로 전이 표현력을 넓혔다. Samba는 SSM과 sliding-window attention을 결합하고, hybrid 연구는 sequential/parallel 배치와 paraphrase data의 영향을 분리한다. MemMamba는 상태 요약과 cross-layer/token attention으로 memory access를 보완한다. 음의 고유값·구조화 전이 연구는 parity와 state tracking의 표현력 한계를 파고든다. SCR-Mamba는 이 흐름에 도메인 구조에 의한 selective control과 increment-only hierarchy를 추가한다.

PART 09 · APPLICATIONS
09

Key Applications

Human motion understanding

운동 분석, 행동 이해, HCI의 3D pose lifting. 직접 근거는 Human3.6M과 MPI-INF-3DHP에 한정된다.

On-device multimodal assistants

텍스트·음성·비전 stream을 구조 조건부 상태로 요약하는 보조기. pose 결과의 직접 일반화가 아니라 연구 가설이다.

Local RAG and streaming analytics

압축 상태로 stream을 추적하고 필요한 구간만 attention·외부 메모리로 정확히 회수하는 계층형 시스템.

Physical AI operations

센서 상태 추적, 사람-로봇 고수준 계획, edge 운영지능. 저수준 제어 안전성은 별도 검증해야 한다.

ETRI/Physical AI 제안사람 skeleton뿐 아니라 로봇 kinematic tree, 접촉 그래프, 설비 topology를 selective parameter의 조건으로 사용한다. 통신 단절·센서 결측 시에는 구조 문맥의 신뢰도를 함께 추정하고, 불확실성이 임계값을 넘으면 외부 증거 메모리 또는 local attention을 호출한다.
PART 10 · OPEN PROBLEMS
10

Open Problems

  • 유한 상태의 과제별 기억 한계: 관절별 구조 문맥이 긴 비주기 동작과 객체 상호작용을 얼마나 보존하는가?
  • 망각 탐지: 필요한 프레임 정보가 상태에서 사라졌음을 출력 전에 감지할 수 있는가?
  • 장기 session drift/reset: 243 프레임을 넘어갈 때 reset·checkpoint·external memory 정책은 무엇인가?
  • 구조 오류: 2D detector가 관절을 뒤바꾸거나 occlusion이 생기면 잘못된 K가 두 분기 모두를 오염시키는가?
  • 저정밀 안정성: quantized Δ·B·C와 hidden state가 긴 시퀀스에서 어떤 누적오차를 만드는가?
  • 공정 비교: 동일 데이터, detector, flip, batch, compiler, 정밀도, hardware에서 attention·SSM·hybrid를 비교할 수 있는가?
  • 실세계·한국어 전문업무: pose benchmark의 state tracking 이점이 agent, 제조, 의료, 한국어 장기 업무로 이어지는가?

MACs와 평균 GPU latency만으로 on-device readiness를 판정해서는 안 된다. p95, peak memory, energy, error recovery, detector 포함 종단 비용이 필요하다.

PART 11 · FUTURE DIRECTIONS
11

Future Directions

1. Hierarchical evidence memory

압축 recurrent state로 지속적으로 추적하되, 불확실성이 커진 구간은 local attention으로 확대하고, 정확한 사실·관측은 외부 evidence memory에서 회수한다. 상태 하나가 tracking·exact recall·provenance를 모두 떠맡지 않게 한다.

2. Adaptive state and scale budgets

동작 변화, occlusion, task risk에 따라 state dimension, coarse scale depth, attention window를 동적으로 늘린다. routing overhead와 실패율을 포함한 종단 최적화가 필요하다.

3. Structure-aware stability tests

관절 swap, frame drop, symmetry violation, sensor delay, 통신 단절을 주입해 상태 오염 탐지율과 reset 후 회복시간을 측정한다. 저정밀 state는 session length별 error growth curve로 보고한다.

4. Success-per-energy benchmark

단순 token/s나 MACs가 아니라 성공 작업당 Joule·p95 지연·근거 회수율·오류복구율을 공동 지표로 삼는다. 비교 모델, 규모, context length, batch, precision, compiler와 하드웨어를 고정한다.

5. ETRI staged validation

단계통제핵심 시험진행 기준
1 · 공개 재현동일 데이터·detector·seed·학습 예산P1/P2, distal error, state-tracking저자 보고 이득의 재현
2 · 동일 장비양자화·batch·compiler·kernelp50/p95, peak memory, Joule/task종단 효율 개선
3 · 상태 오염occlusion·swap·drop·통신 단절탐지율, reset cost, recovery ratesilent failure 한계 충족
4 · 장기 실증사람-로봇·설비 실제 stream임무 성공률, 근거 회수율, 안전 위반현장 baseline 대비 유의한 이점
제안온디바이스 협업지능 과제에서는 동일 학습데이터·양자화·하드웨어 비교를 사전 고정하고, 구조 문맥 오염과 통신 단절 시험을 통과한 뒤 장기 로봇·설비 실증으로 이동한다. 저수준 제어는 별도 safety case와 독립 fallback을 요구한다.

SCR-Mamba가 증명한 것은 “Mamba가 3D pose를 해결했다”가 아니다. 더 정확한 결론은 이렇다. 도메인 구조는 상태 갱신을 직접 조절할 수 있고, 거친 시간척도는 전체 표현이 아니라 새로 얻은 변화만 세밀한 표현에 전달할 수 있다. 다음 연구는 이 통찰이 코드 재현, 저정밀 장기 안정성, 실제 단말 임무 비용에서도 유지되는지 검증해야 한다.
