Transformer Architecture:
Why Attention Replaced Recurrence

Transformer의 핵심은 attention을 더 잘 썼다는 데만 있지 않다. 순차 계산을 모델 구조의 필수 조건으로 보던 관점을 바꾸고, 토큰 간 관계 계산을 대규모 행렬 연산으로 재배치한 데 있다.

1. 문제는 기억보다 계산 순서에 있었다

2017년의 주류 sequence transduction 모델은 RNN, LSTM, GRU 계열의 encoder-decoder였다. attention은 이미 널리 쓰였지만 대개 recurrent network 위의 보조 메커니즘이었다. Vaswani 등은 recurrent state의 시간축 의존성이 학습을 직렬화하는 병목이라고 본다. 그래서 recurrence와 convolution을 모두 제거하고 입력과 출력 위치 사이의 관계를 attention으로 직접 연결하는 Transformer를 제안한다.

분석. 핵심 전환은 시간축을 따라 상태를 전달하는 계산에서 모든 위치 사이의 관계를 한 번에 계산하는 그래프로 바뀐 데 있다. 이는 표현 학습과 하드웨어 효율을 동시에 겨냥한 구조적 선택이다.

2. Self-attention은 토큰을 직접 연결한다

Scaled dot-product attention은 query와 key의 내적에 1/√dk를 곱한 뒤 softmax를 적용하고, 그 가중치로 value를 합성한다. 스케일링은 key 차원이 커질 때 내적의 크기가 커져 softmax가 작은 gradient 영역으로 밀리는 현상을 완화하려는 장치이다.

Base model은 8개 head를 사용하고 dmodel=512를 head별 64차원 query/key/value 공간으로 투영한다. Multi-head attention은 하나의 평균적 관계 표현 대신 여러 learned subspace에서 서로 다른 관계를 병렬로 포착하게 한다.

원문이 보여주는 것. Appendix의 시각화는 일부 head가 장거리 의존성, 대명사 참조, 문장 구조와 관련된 패턴을 보인다고 보고한다. 다만 이는 qualitative observation이며 attention weight 자체가 모델 결정의 완전한 인과 설명임을 입증하지는 않는다.

3. Encoder-decoder 골격은 유지하고 내부 연산을 교체한다

Encoder self-attention

각 위치가 이전 encoder layer의 모든 위치를 볼 수 있다.

Masked decoder attention

미래 위치를 masking해 autoregressive 조건을 보존한다.

Cross-attention

Decoder query가 encoder의 key/value를 읽는다.

Base model의 encoder와 decoder는 각각 6개 layer이며 주요 sub-layer 출력 차원은 512이다. Position-wise feed-forward network는 512→2048→512이고 residual connection과 layer normalization이 적용된다. Recurrence가 사라지면서 순서를 직접 주입해야 하므로 sinusoidal positional encoding을 embedding에 더한다. Learned positional embedding도 거의 같은 결과를 보였다고 보고한다.

4. 왜 더 병렬적인가

LayerComplexitySequential opsMax path
Self-attentionO(n²d)O(1)O(1)
RecurrentO(nd²)O(n)O(n)
ConvolutionalO(knd²)O(1)O(logkn)

논문은 n<d인 조건에서 self-attention이 recurrent layer보다 계산적으로 유리하다고 설명한다. 하지만 full attention에는 O(n²) 항이 남는다. 긴 입력에서 이 비용이 커지는 문제를 저자들도 인식하고 restricted attention을 후속 방향으로 언급한다.

주의. Layer 내부의 sequential operation이 O(1)이라는 사실은 학습 시 위치별 계산의 병렬화를 뜻한다. Autoregressive decoding의 token 생성 자체가 완전히 병렬이 되었다는 뜻은 아니다.

5. 학습 레시피

영어→독일어 실험은 WMT 2014의 약 450만 문장쌍과 약 37,000 token의 shared BPE vocabulary를 사용한다. 영어→프랑스어는 3,600만 문장과 약 32,000 word-piece vocabulary를 사용한다. Batch는 대략 25,000 source token과 25,000 target token으로 구성된다.

Optimizer는 Adam(β₁=0.9, β₂=0.98, ε=10⁻⁹)이며 learning rate는 처음 4,000 step 동안 선형 증가한 뒤 inverse square root schedule로 감소한다. Residual dropout과 label smoothing도 사용한다. 한 대의 machine에서 8개의 NVIDIA P100 GPU를 사용했고 base model은 100K step에 약 12시간, big model은 300K step에 약 3.5일 학습했다고 보고한다.

6. 실험 결과와 ablation

WMT 2014 영어→독일어 newstest2014에서 Transformer (big)는 28.4 BLEU, base는 27.3 BLEU를 기록한다. 논문은 big model이 당시 보고된 최고 모델과 ensemble보다 2 BLEU 이상 높았다고 기술한다.

Ablation에서 base configuration의 development BLEU는 25.8이고 single-head는 24.9, 32-head는 25.4이다. Learned positional embedding은 25.7로 sinusoidal base의 25.8과 거의 같다. 영어 constituency parsing에서는 WSJ-only setting에서 91.3 F1, semi-supervised setting에서 92.7 F1을 보고한다. 이는 번역 외 task에서도 구조가 작동한다는 보조 증거지만 표 안의 모든 비교 모델을 능가한 것은 아니다.

7. 한계와 주의점

첫째, 원 논문의 실험 범위는 주로 machine translation과 constituency parsing이다. 이미지·오디오·비디오 같은 다른 modality는 future work로 제시될 뿐 이 논문에서 검증되지 않는다. 둘째, full self-attention은 sequence length에 대해 quadratic cost를 가진다. 셋째, attention visualization은 흥미로운 패턴을 보여주지만 interpretability의 완전한 검증은 아니다. 넷째, 당시 state-of-the-art라는 표현은 2017년 benchmark 문맥에 묶여 있으며 오늘의 최신 모델과 직접 비교한 결과가 아니다.

8. 무엇이 실제로 바뀌었나

Transformer의 새로움은 개별 부품 하나의 발명보다 부품의 재배치에서 더 선명하다. Attention, encoder-decoder, residual connection, layer normalization은 선행 연구가 있었지만 Transformer는 이들을 조합해 sequence modeling에서 recurrence를 필수 요소의 자리에서 밀어냈다. Token 간 경로는 짧아졌고, 학습 시 위치별 연산은 대규모 matrix operation으로 묶기 쉬워졌다. Positional encoding은 순서를 recurrence의 시간축이 아니라 명시적 representation으로 옮긴다.

추론. 장기적 의미를 찾는다면 특정 BLEU 숫자보다 계산 그래프를 hardware-friendly하게 재구성할 수 있음을 보여준 데 있다. 다만 이후의 대규모 언어 모델 성능을 이 2017년 논문 하나가 직접 입증한 것으로 소급해서는 안 된다.

9. 핵심 정리

  • 핵심은 attention 추가보다 recurrence 제거이다.
  • Self-attention은 layer 내에서 모든 위치를 직접 연결해 dependency path를 줄인다.
  • 병렬성의 이점과 O(n²) 장문 비용은 동시에 존재한다.
  • 논문의 설득력은 WMT 결과, ablation, parsing transfer, 구체적 학습 레시피를 함께 볼 때 커진다.
